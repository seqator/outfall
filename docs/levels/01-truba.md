# Уровень: «Труба» — левел-дизайн пролога (OF-014)

> Владелец: `level-designer`. Источники: `docs/OUTFALL-CONCEPT.md` §6 («Первые 60
> секунд», обязательный сценарий), `docs/narrative/world-bible.md` §2.1
> (локация «Труба»: Санитар, Серёга Сачок, задвижка, латунный ключ),
> `docs/narrative/main-quest.md` §0–2 (пролог и `flag.prolog_vybor`),
> `docs/design/combat.md` §2.1 (враг «раки» среза), `docs/art/art-bible.md`
> §2.1/§2.3 (тайл 64×32, читаемость боя).
> Не входит в этот документ: диалоги целиком (OF-024), боевые формулы
> (`docs/design/combat.md` не меняется), сама карта в JSON по `MapSchema`
> (OF-025). Здесь — намерение дизайнера уровня: геометрия, тайминг, точки
> энкаунтеров и выбора, с координатами для последующей реализации.
> Канонический id карты — `map.truba` (уже используется в тестовых
> фикстурах `tests/fixtures/data/valid/maps/truba.json`).

## 0. Формат схемы

- Карта **64×64 тайла** (64×32 px изометрический тайл, `art-bible.md` §2.1),
  ось `x`: 0 (запад) → 63 (восток), ось `y`: 0 (устье трубы, старт игрока) →
  63 (выход к реке, финал пролога). Игрок физически идёт «на юг» по схеме —
  это соответствует спуску вглубь коллектора; в изометрическом рендере
  ориентация «север — вверх-вправо» (`art-bible.md` §2.1) не меняет саму
  геометрию карты, только угол камеры.
- ASCII-схема ниже — обзорная, **1 символ = 2×2 тайла** (32×32 клетки на
  64×64 карту), только для читаемости общего плана. Все координаты в
  таблицах триггеров/спавнов/лута — **реальные тайлы (0–63)**, они являются
  источником истины для OF-025, а не пересчёт из ASCII.
- Ширина всех проходов ≥ 5 тайлов, коридоры выровнены по осям `x`/`y`, без
  диагональных «бутылочных горлышек» под 45° — требование читаемости
  изометрии из задания OF-014.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимый бетон, коллизия 1 |
| `.` | пол коллектора, бетон, проходимо |
| `~` | вода (после подъёма затвора), проходимо с замедлением |
| `S` | точка старта игрока |
| `P` | точка панорамной камеры (3–8 с) |
| `?` | плакат «Сброс временно ограничен», декор |
| `V` | задвижка (интерактивный объект сцены 15–25 с) |
| `@` | громкая связь / динамик Санитара |
| `L` | лестница на мостки (высотная точка) |
| `K` | мостки (приподнятая дорожка вдоль восточной стены) |
| `C` | колонна/укрытие (блокирует линию огня, не силуэт) |
| `O` | бочка (взрывоопасный объект) |
| `X` | секрет — тайник за оторванной решёткой |
| `a` `b` `c` | точки спавна раков (см. §4) |
| `R` | Родион «Ключик» Углов, тонущий энергосбытовец |
| `E` | решётка выхода к реке (финал пролога) |
| `Z` | Серёга Сачок, NPC-декор у выхода |
| `1`–`6` | триггеры T1–T6 (см. §3) |

## 1. Схема по зонам (1 симв. = 2×2 тайла)

Тоннель узкий (Зона B) внутри широких залов (A, C, D) — единая сетка 32×32
дала бы нечитаемый разброс пропорций, поэтому схема разбита по зонам,
сверху вниз по порядку прохождения; координаты у каждой зоны — реальные
тайлы (0–63).

### Зона A — Панорама (y 0–9, 3–8 с)

```
y00 ####...P....####
y02 ####...S....####
y04 ####.........####
```

Платформа-«губа» водосброса, `x 18–44`, огорожена низким парапетом. `P`
(30,2) — статичный якорь камеры, смотрит на юг вдоль тела Плотины; `S`
(30,6) — старт игрока, на 2 тайла южнее.

### Зона B — Спуск (y 10–19, 8–15 с)

```
y11 ######...#######
y13 #####?..1#######
```

Пандус вниз, `x 26–34` (ширина 8 тайлов, прямой коридор по оси Y, без
диагоналей). `?` — плакат «Сброс временно ограничен» (26,14), `1` —
триггер T1, подсказка управления (30,14).

### Зона C — Задвижка / смотровая (y 20–29, 15–25 с)

```
y21 ####...........####
y23 ####...2....@..####
y25 ####....V......####
y27 ####~.........L.####
```

Зал шире коридора, `x 16–44`. `2` — T2 (30,22): Санитар по громкой связи
`@` (38,22), открывает сброс; `V` — задвижка (30,24), заклинена (деталь
декора, предвосхищает сцену «Полчаса» из `main-quest.md`); `~` (24,26) —
точка входа воды; `L` (42,26) — лестница на мостки `K` вдоль восточной
стены.

### Зона D — Коллектор-арена (y 30–47, 25–40 с)

```
y31 #######.........K#########
y33 #######........3......K.#
y35 #######...C.......C.c.K.#
y37 #######.a..O...........K#
y39 #######.......C........K#
y41 #######.............C.K.#
y43 #######.X.......b.....K.#
y45 #######..............L..#
```

Главный зал боя, `x 14–46`, прямоугольный, без узких диагоналей. `3` — T3
(30,34), запускает волну раков. Спавны `a` (18,38), `b` (32,44), `c`
(40,36) — три открытых выхода из воды, читаются по всплеску и красному
телеграфу (`art-bible.md` §2.3 п.6). `C` — 4 колонны-укрытия ((20,36),
(36,36), (28,40), (40,42)), укрытие по пояс, не блокируют силуэт. `O` —
бочка (24,38), взрывоопасный объект. `K`/`L` — мостки (высотная точка) и
вторая лестница вниз (44,46). `X` — секрет (16,44), см. §6.

### Зона E — Затопленный коридор / выбор (y 48–55, 40–52 с)

```
y49 ~~~~4~~~~
y51 ~~~~~~~~~
y53 ~~~~R~~~~
y55 ~~~~5~~~~
```

Узкий (`x 22–38`), полностью затопленный — единственный путь дальше, вода
по грудь. `4` — T4 (30,48), запускает сцену выбора и таймер; `R` — Родион
«Ключик» Углов, придавлен решёткой (30,52); `5` — T5 (30,54), фиксирует
исход и флаг.

### Зона F — Выход к реке / крючок (y 56–63, 52–60 с)

```
y57 .........
y59 ...6.....
y61 ...E..Z..
y63 .........
```

Решётка выхода `E` (30,61) открывается в устье, за ней — река и дневной
свет (задник, не часть игровой геометрии). `6` — триггер T6 (30,58): рация
и титр «Глава 1. Труба». `Z` — Серёга Сачок (36,60), decor-NPC с сачком у
решётки (первая шутка игры, per `world-bible.md` §2.1) — присутствие без
диалога в скоупе OF-014, полный текст — задача narrative-writer.

Мостки `K`/лестницы `L` — не триггеры, а геометрия (высотная точка); при
реализации в `MapSchema` (плоская 2D-сетка коллизий) элевация мостков
физически не поддержана схемой — level-designer фиксирует намерение
(приподнятый спрайт + отдельная проходимая полоса вдоль восточной стены),
техническое решение (доп. слой высоты или обычная проходимая клетка с
визуальным смещением) — за `engine-architect`/OF-015.

## 6. Секрет и нелинейный путь

**Секрет.** Тайник `X` (16,44) в зоне D — ниша за оторванной решёткой у
западной стены арены, замаскирована под обычный кусок стены визуально
(лёгкий сдвиг текстуры, без явного маркера в финальном арте — маркер `X` в
ASCII-схеме служебный, для дизайнера). Открывается любым способом на
выбор: `[Взлом]` без порога (замок ржавый, ломается голыми руками при
попытке), выстрелом по бочке `O` рядом (взрыв срывает решётку) или просто
подходом вплотную и взаимодействием — решётка изначально полуоторвана.
Награда — `item.ammo_9mm` ×8 и `item.mat_detali` ×3 (см. §5), достаточно
скромная, чтобы не обесценить открытый бой в арене, но заметная для
внимательного игрока.

**Нелинейный путь.** Мостки `K` вдоль восточной стены (доступны с
лестницы `L`, тайл 42,26, зона C) — обход основного пути по полу арены.
Игрок, поднявшийся на мостки **до** входа в радиус T3 (30,34), проходит
вдоль всей арены на высоте, минуя триггер спавна раков `c` (40,36) — этот
рак не выходит из воды, если игрок ни разу не спускался в радиус T3 по
полу. Раки `a` и `b` всё равно могут заметить игрока по звуку шагов на
мостках (внутриигровой шум, не в скоупе level-design), так что полный
стелс не гарантирован — это риск, а не гарантированный пропуск боя.
Мостки также ведут прямо ко второй лестнице `L` (44,46), спускающей у
самого края зоны E — то есть обходной путь не «читерский шорткат в
никуда», а полноценный параллельный маршрут с тем же выходом. Для игрока
без навыка скрытности стандартный путь по полу арены остаётся основным и
гарантированно даёт полноценный первый бой, как того требует концепт §6
(«25–40: первый бой… умирают за секунды, рывок сквозь клешню»).

## 8. Читаемость и бой — проверка по требованиям задачи

- **Укрытия/узкие места**: 4 колонны в зоне D, ширина всех коридоров ≥5
  тайлов (зона B — 8, зона E — узкая 9-тайловая по замыслу «вода зажимает»,
  но не диагональная и не уже правила читаемости).
- **Взрывоопасный объект**: бочка `O` (24,38), у скопления укрытий.
- **Высотная точка**: мостки `K` вдоль восточной стены зоны C/D — обзор
  сверху, недоступен рачьему рывку по прямой (рашер бьёт по горизонтали).
- **Враги без укрытия за стеной без индикации**: все три точки спавна раков
  — открытые всплески воды с красным телеграфом, видны из любой точки
  арены.
- **Чередование темпа**: просмотр (5с) → исследование (7с) → диалог+событие
  (10с) → бой (15с) → диалог+выбор (12с) → диалог-крючок (8с) — ни один блок
  не превышает 90 с одного типа (максимум — 15 с).
- **Первый бой и первый выбор в первые 2–3 минуты**: оба укладываются в
  первые 60 секунд игры, с запасом по требованию концепта.
