> Владелец: `level-designer`. Источники: `docs/OUTFALL-CONCEPT.md` §6

## 0. Формат схемы

Карта **64×64 тайла** (тайл 64×32 px, `art-bible.md` §2.1). Ось `x`: 0
(запад) → 63 (восток); ось `y`: 0 (устье, старт) → 63 (выход к реке,
финал). ASCII-схемы ниже — обзорные (**1 символ = 2×2 тайла**), для общей
читаемости плана; координаты в таблицах §3–§5 — реальные тайлы (0–63) и
источник истины для OF-025. Ширина проходов ≥5 тайлов, коридоры выровнены
по осям `x`/`y`, без диагональных «бутылочных горлышек» под 45°.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимый бетон, коллизия 1 |
| `.` | пол коллектора, бетон, проходимо |
| `~` | вода (после подъёма затвора), проходимо с замедлением |
| `S` | точка старта игрока |
| `P` | точка панорамной камеры (3–8 с) |
| `?` | плакат «Сброс временно ограничен», декор |
| `V` | задвижка (интерактивный объект сцены 15–25 с) |
| `@` | громкая связь / динамик Санитара |
| `L` | лестница на мостки (высотная точка) |
| `K` | мостки (приподнятая дорожка вдоль восточной стены) |
| `C` | колонна/укрытие (блокирует линию огня, не силуэт) |
| `O` | бочка (взрывоопасный объект) |
| `X` | секрет — тайник за оторванной решёткой |
| `a` `b` `c` | точки спавна раков (см. §4) |
| `R` | Родион «Ключик» Углов, тонущий энергосбытовец |
| `E` | решётка выхода к реке (финал пролога) |
| `Z` | Серёга Сачок, NPC-декор у выхода |
| `1`–`6` | триггеры T1–T6 (см. §3) |

## 1. Схема по зонам (1 симв. = 2×2 тайла)

Тоннель узкий (Зона B) внутри широких залов (A, C, D) — единая сетка 32×32
дала бы нечитаемый разброс пропорций, поэтому схема разбита по зонам,
сверху вниз по порядку прохождения; координаты у каждой зоны — реальные
тайлы (0–63).

### Зона A — Панорама (y 0–9, 3–8 с)

```
y00 ####...P....####
y02 ####...S....####
y04 ####.........####
```

Платформа-«губа» водосброса, `x 18–44`, огорожена низким парапетом. `P`
(30,2) — статичный якорь камеры, смотрит на юг вдоль тела Плотины; `S`
(30,6) — старт игрока, на 2 тайла южнее.

### Зона B — Спуск (y 10–19, 8–15 с)

```
y11 ######...#######
y13 #####?..1#######
```

Пандус вниз, `x 26–34` (ширина 8 тайлов, прямой коридор по оси Y, без
диагоналей). `?` — плакат «Сброс временно ограничен» (26,14), `1` —
триггер T1, подсказка управления (30,14).

### Зона C — Задвижка / смотровая (y 20–29, 15–25 с)

```
y21 ####...........####
y23 ####...2....@..####
y25 ####....V......####
y27 ####~.........L.####
```

Зал шире коридора, `x 16–44`. `2` — T2 (30,22): Санитар по громкой связи
`@` (38,22), открывает сброс; `V` — задвижка (30,24), заклинена (деталь
декора, предвосхищает сцену «Полчаса» из `main-quest.md`); `~` (24,26) —
точка входа воды; `L` (42,26) — лестница на мостки `K` вдоль восточной
стены.

### Зона D — Коллектор-арена (y 30–47, 25–40 с)

```
y31 #######.........K#########
y33 #######........3......K.#
y35 #######...C.......C.c.K.#
y37 #######.a..O...........K#
y39 #######.......C........K#
y41 #######.............C.K.#
y43 #######.X.......b.....K.#
y45 #######..............L..#
```

Главный зал боя, `x 14–46`, прямоугольный, без узких диагоналей. `3` — T3
(30,34), запускает волну раков. Спавны `a` (18,38), `b` (32,44), `c`
(40,36) — три открытых выхода из воды, читаются по всплеску и красному
телеграфу (`art-bible.md` §2.3 п.6). `C` — 4 колонны-укрытия ((20,36),
(36,36), (28,40), (40,42)), укрытие по пояс, не блокируют силуэт. `O` —
бочка (24,38), взрывоопасный объект. `K`/`L` — мостки (высотная точка) и
вторая лестница вниз (44,46). `X` — секрет (16,44), см. §6.

### Зона E — Затопленный коридор / выбор (y 48–55, 40–52 с)

```
y49 ~~~~4~~~~
y51 ~~~~~~~~~
y53 ~~~~R~~~~
y55 ~~~~5~~~~
```

Узкий (`x 22–38`), полностью затопленный — единственный путь дальше, вода
по грудь. `4` — T4 (30,48), запускает сцену выбора и таймер; `R` — Родион
«Ключик» Углов, придавлен решёткой (30,52); `5` — T5 (30,54), фиксирует
исход и флаг.

### Зона F — Выход к реке / крючок (y 56–63, 52–60 с)

```
y57 .........
y59 ...6.....
y61 ...E..Z..
y63 .........
```

Решётка `E` (30,61) открывается в устье, за ней — река и дневной свет
(задник). `6` — T6 (30,58): рация и титр «Глава 1. Труба». `Z` — Серёга
Сачок (36,60), decor-NPC (первая шутка игры, `world-bible.md` §2.1);
диалог — задача narrative-writer.

| Сек | Зона карты | Что видит/делает игрок | Тип темпа |
|---|---|---|---|
| 0–3 | — (титульник, не часть карты) | Загрузка ≤ 3 с, одна кнопка | — |
| 3–8 | A, точка `P` (30,2) → `S` (30,6) | Камера статична на `P`, показывает Плотину (турбинный зал, крупный силуэт вверху кадра), провода Оголённой линии вправо, силуэты Панелей вдалеке слева — всё за северным краем платформы, как задник (не игровая геометрия). Одна строка текста | Исследование (просмотр) |
| 8–15 | B, коридор `x26–34` | Игрок получает управление, спуск по пандусу; `?` плакат читается на ходу; `1` T1 — одна строка подсказки WASD/мышь | Исследование |
| 15–25 | C, зал `x16–44` | `2` T2: Санитар по громкой связи `@`, грубая реплика по делу + первая проверка `[Язык]`/`[Смекалка ≤3]`; вода начинает прибывать от `~` (24,26); задвижка `V` показана крупным планом | Диалог + событие |
| 25–40 | D, арена `x14–46` | `3` T3: волна раков (`a`,`b`,`c`), 2–3 шт., укрытия `C`, бочка `O`, мостки `K` как высотная точка | Бой |
| 40–52 | E, коридор `x22–38` | `4` T4: вода по грудь, `R` (30,52) — тонущий Родион, таймер идёт; выбор «вытащить» / «снять ключ»; `5` T5 фиксирует флаг | Диалог + выбор (время идёт) |
| 52–60 | F, зона выхода `x24–40` | `6` T6: рация — «Веденеев запросил мощность на НИИ. Опять»; титр «Глава 1. Труба»; игра не останавливается | Крючок (диалог, коротко) |

Каждый блок ≤ 15 с одного типа темпа (макс. блок — бой, 15 с) — с запасом
укладывается в правило «не более 90 секунд подряд одного типа».

фиксируется только намерение (приподнятый спрайт + отдельная проходимая
полоса); техническое решение — за `engine-architect`/OF-015.

## 6. Секрет и нелинейный путь

**Секрет.** Тайник `X` (16,44) в зоне D — ниша за полуоторванной решёткой
у западной стены, замаскирована под обычную стену (маркер `X` — служебный,
для дизайнера, не для игрока). Открывается любым способом: `[Взлом]` без
порога, выстрел по бочке `O` рядом (взрыв срывает решётку) или просто
взаимодействие вплотную. Награда — `item.ammo_9mm` ×8 и `item.mat_detali`
×3 (§5) — скромно, чтобы не обесценить открытый бой, но заметно для
внимательного игрока.

**Нелинейный путь.** Мостки `K` (доступ с лестницы `L`, 42,26, зона C) —
обход пути по полу арены. Игрок, поднявшийся на мостки **до** входа в
радиус T3 (30,34), не будит спавн `c` (40,36) — рак не выходит из воды,
пока игрок ни разу не спускался в радиус T3. Раки `a`/`b` всё же могут
заметить шаги на мостках — полный стелс не гарантирован, это риск, а не
чит. Мостки ведут ко второй лестнице (44,46) у края зоны E — полноценный
параллельный маршрут, не тупиковый шорткат. Стандартный путь по полу
остаётся основным и даёт полноценный первый бой, как требует концепт §6.

## 8. Читаемость и бой — проверка по требованиям задачи

- **Укрытия/узкие места**: 4 колонны в зоне D; ширина коридоров ≥5 тайлов
  (B — 8, E — 9, «вода зажимает», но не диагональ и не уже правила).
- **Взрывоопасный объект**: бочка `O` (24,38).
- **Высотная точка**: мостки `K` вдоль восточной стены C/D — обзор сверху,
  недоступен прямому рывку рака.
- **Враги без индикации**: все спавны раков — открытые всплески с красным
  телеграфом, видны с любой точки арены.
- **Чередование темпа**: просмотр 5с → исследование 7с → диалог+событие
  10с → бой 15с → диалог+выбор 12с → крючок 8с — максимум 15с одного типа
  подряд, с запасом от лимита 90с.
- **Первый бой и выбор в первые 2–3 минуты**: оба — в первые 60с игры.
