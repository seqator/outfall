## 0. Формат схемы

Карта **54×40 тайла**. Ось `x`: 0 (запад, к Гаражам) → 53 (восток, к
Панелям); ось `y`: 0 (север) → 39 (юг, к Трубе/реке). 1 символ ASCII-схемы
= 2×2 тайла. Ширина проходов ≥5 тайлов на главных маршрутах; турбинные
колонны — прямоугольные заливки 2×2, не диагональ.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимая клетка |
| `.` | пол, проходимо |
| `S` | точка спавна героя |
| `Z` | Зоя Ильинична «Тарифница» |
| `M` | Модест Бусыгин |
| `K` | Клавдия Бусыгина |
| `C` | турбинная колонна (укрытие/препятствие, декор) |
| `1` | триггер `trigger_modest_checkpoint` |
| `2` | триггер `trigger_shluz` (условие — латунный ключ) |
| `X` | секрет — служебный шлюз |
| `>` | выходы (`exit_to_garazhi`, `exit_to_paneli`, `exit_to_truba`) |

## 1. Схема по зонам (1 симв. = 2×2 тайла)

Планировка — «гантель»: большой машинный зал в центре, три придатка
(кабинет Зои на севере, больница на востоке, служебный шлюз-секрет на
северо-западе) плюс южный вход с двумя параллельными маршрутами к залу —
прямой (через администратора Модеста) и обходной западный.

### Зона A — Служебный шлюз (секрет), `x 9–14, y 4–9`

```
y04 ######
y06 #X2..#      X/2 — pickup + trigger_shluz (11,6)/(12,6-7)
y08 #.....#
```

Латунный ключ из пролога (`item.quest_klyuch_shlyuza`) находит здесь
физическую отсылку: `trigger_shluz` (11,6) срабатывает только при
`hasItem item.quest_klyuch_shlyuza` — если игрок выбрал в Трубе `klyuch`
(снял ключ вместо спасения Родиона), заход сюда даёт дополнительный флаг
`flag.plotina.shluz_key_used`. Если ключа нет (исход `spas`) — комната всё
равно физически доступна и даёт лут, просто без флага.

### Зона B — Кабинет Зои, `x 15–22, y 4–9`

```
y04 ########
y06 #..Z....#
y08 #........#
```

`Z` (18,6) — Зоя Ильинична «Тарифница». Примыкает к машинному залу без
отдельного коридора (общая граница `y9/y10`).

### Зона C — Машинный зал, `x 8–45, y 10–23`

```
x08                x27         x36      x45
y10 ###############################
y12 #.C....C..............C.....#     C — турбинные колонны
y14 #............................#        (14,15)/(20,15)/(30,17)/(36,15), 2×2
y16 #............................#
y18 #.$..........................#     $ (15,18) — pickup патронов
y20 #............................#
y22 #............................#
y23 ###############################
```

Работает «на треть мощности» (`world-bible.md` §2.2) — колонны читаются
как турбины, стоящие вразнобой, не сплошным рядом. Зал — главный
перекрёсток: с юга (админ-коридор и западный обход), с севера (кабинет
Зои и шлюз), с востока (больница), на восток дальше — выход к Панелям.

### Зона D — Больница, `x 46–51, y 6–23`

```
y06 ######
y08 #....#
y14 #.K..#      K (48,14) — Клавдия Бусыгина
y15 #..$.#      $ (49,15) — аптечка
y23 ######
```

### Зона E — Вход и админ-коридор (прямой маршрут), `x 20–33, y 24–37`

```
y24 ..M..              M (26,27) — Модест Бусыгин, 1 — trigger_modest_checkpoint
y27 ..1..
y31 ......
y32 ..........S...
y37 ..........
```

`S` — точка спавна (по факту — зал, `findSpawnPoint` берёт центр карты).
Модест стоит в горле коридора между южным входом и залом — обязательная
точка встречи для тех, кто идёт «в лоб».

### Зона F — Западный обход (нелинейный путь), `x 9–13, y 24–31` + связка `x13–20,y29–31`

```
y24 ....
y29 .......
y31 .......
```

Соединяет южный вход напрямую с залом вдоль западной стены, минуя
`trigger_modest_checkpoint`. Подтверждено BFS: зал, кабинет Зои и шлюз
достижимы даже при полностью заблокированном радиусе КПП Модеста.

## 2. Темп и чередование

Как и Гаражи, Плотина — хаб-локация фракции, без обязательного боя (у
Энергосбыта нет отдельного врага в `combat.md` §2 — «Энергосбытовец»
элита введена в игру, но не как хостильная охрана на своей территории, а
как враждебная единица в других контекстах; помещать её здесь означало
бы воевать со своими). Секрет-шлюз и западный обход дают геймплейный
акцент без стрельбы.

| Блок | Зона | Тип темпа |
|---|---|---|
| Вход, Модест | E | Диалог (квест-хук `quest.klyuch_tarifnicy`, рубильник) |
| Зал, турбины | C | Исследование |
| Кабинет Зои | B | Диалог (ядро Q2 — судьба ключа/Родиона) |
| Шлюз-секрет | A | Исследование (опционально, реакция на предмет) |
| Больница, Клавдия | D | Диалог (крючок `quest.schetchik_i_sovest`) |

## 6. Секрет и нелинейный путь

**Секрет.** Служебный шлюз (зона A) — канонический объект
`world-bible.md` §2.2 («служебный шлюз, до которого ведёт латунный ключ из
пролога»). Комната тупиковая, в стороне от главного маршрута зал↔кабинет
Зои; `trigger_shluz` с условием `hasItem` — единственный на всех трёх
новых картах пример использования `condition` в триггере, тематически
завершающий сюжетную ниточку пролога независимо от диалогов.

**Нелинейный путь.** Зона F — западный обход входа, минует
`trigger_modest_checkpoint`. Игрок может попасть в зал/к Зое, не
разговаривая с Модестом первым (например, если репутация Энергосбыта уже
испорчена и разговаривать с его человеком нежелательно).

## 7. Связь с флагами `main-quest.md`

- Зоя — центральный NPC Q2 («Ключ Тарифницы»): судьба ключа/Родиона
  (`flag.prolog_vybor`), проверка `[Язык ≥ 5]` при вопросе «где Родион?».
  Физически размещена в кабинете (зона B), примыкающем к залу.
- Модест — квест-хук сцены дерзости «Рубильник» (`flag.rubilnik`,
  `main-quest.md` §3) и отдельного фракционного квеста
  `quest.schetchik_i_sovest` (в паре с Клавдией). Сам рубильник —
  физический объект на `map.paneli` (щиток подъезда, §7 в `04-paneli.md`);
  Модест здесь только даёт задание — согласовано с тем, как main-quest.md
  описывает «исполнитель — Модест Бусыгин» на Панелях.
- Клавдия — крючок `quest.schetchik_i_sovest`, действует «в обход мужа»
  (её же собственного дома, зона E) — физически они на одной карте, но в
  разных зонах, что соответствует «тайком» из описания квеста.
- Родион «Ключик» Углов **не размещён** на этой карте: он уже существует
  как `npc.rodion` на `map.truba` (сцена пролога в воде); дублировать id
  нельзя (глобальная уникальность NPC, `tools/validate-data.ts`), а
  полноценного перемещения NPC между картами по флагу движок пока не
  поддерживает (нет системы переключения карт, см. `docs/BACKLOG.md`
  OF-033). Решение level-designer: не размещать его здесь в этой волне —
  это не критично для карты по формулировке задачи; будущая интеграция
  (например, отдельный `npc.rodion_plotina` с условным спавном) — вне
  скоупа OF-033.

## 8. Читаемость и проверка по требованиям задачи

- **Нелинейный путь**: западный обход (§6).
- **Секрет**: служебный шлюз (§6).
- **Главный конфликт локации**: рубильник — герой либо исполняет
  отключение Панелей по просьбе Модеста, либо отказывает; сама развилка
  физически на другой карте (Панели), но здесь — точка получения задания.
- **История в декорациях**: турбины на треть мощности, доска тарифов
  (подразумевается в зале, декор без отдельной коллизии), кабинет Зои
  рядом с залом — «власть через учёт», а не через кабинет за семью
  дверями.
- **Чередование темпа**: см. §2, боя нет (осознанное решение, как и в
  Гаражах — Энергосбыт не воюет со своими на собственной территории).
- **Ширина проходов / без диагоналей**: ≥5 тайлов на главных маршрутах;
  турбинные колонны — заливки 2×2, не цепочка одиночных клеток.
- **Проверка проходимости**: `tests/unit/game/world/act1-maps.test.ts` +
  ручная проверка (см. отчёт задачи) — зал, кабинет Зои и секрет-шлюз
  достижимы даже при полностью заблокированном радиусе
  `trigger_modest_checkpoint`.
