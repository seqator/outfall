## 0. Формат схемы

Карта **44×34 тайла** (тайл 64×32 px). Ось `x`: 0 (запад) → 43 (восток);
ось `y`: 0 (север, депо) → 33 (юг, вход со стороны города/Трубы). ASCII-схемы
ниже — обзорные (**1 символ = 2×2 тайла**); координаты в таблицах —
реальные тайлы (0–43), источник истины для контента. Ширина проходов
≥5 тайлов (кроме второстепенных ответвлений к отдельным боксам, где
допустима ширина 2–4 — это не боевые узкие места, а хабовые аппендиксы);
все препятствия — прямоугольные заливки, ни одной диагональной
«лесенки»/бутылочного горлышка под 45°.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимая клетка, коллизия 1 |
| `.` | пол, проходимо |
| `S` | точка спавна героя (по факту — ближайшая проходимая к центру карты, `findSpawnPoint`) |
| `G` | Гриня (Григорий), начальник охраны |
| `P` | Пересказчик, рынок |
| `N` | Дядя Гена, машинист трамвая №7 |
| `V` | Виктор Павлович «Палыч», кузница/верстак |
| `1` | триггер `trigger_grinya_checkpoint` |
| `X` | секрет — бокс «2207» |
| `>` | выход `exit_to_plotina` |
| `o` | точечное препятствие (рыночный лоток) |
| `=` | автомат с газировкой (пасхалка, декор, без коллизии) |

## 1. Схема по зонам (1 симв. = 2×2 тайла)

Компактный хаб без единого линейного маршрута: рынок в центре, от него
четыре луча — депо (север), кузница Палыча (восток), барак отработчиков
(запад) и вход/КПП Грини (юг), плюс обходная тропа вдоль западной стены,
не проходящая через КПП.

### Зона A — Депо (трамвайное депо №7), `x 9–33, y 2–9`

```
x09       x14  x18      x25       x33
y02 #########################
y04 #.....N.................#
y06 #........................#
y08 #........................#
```

Открытый зал `x9–33,y2–9`. `N` (14,5) — Дядя Гена у стоящего трамвая
(декоративный вагон подразумевается вдоль восточной стены, `x25–30`, без
отдельной коллизии — пропс). Депо примыкает к рынку без отдельного
коридора (общая граница `y9/y10`).

### Зона B — Рынок (плаза), `x 9–33, y 10–17`

```
y10 #########################
y12 #..o.P..................#
y14 #.......$>...............#
y16 #.......................o#
y17 #########################
```

`P` (12,13) — Пересказчик («Кратко про — банка. Подробно — две»,
`world-bible.md` §7). `o` (18,12) и (27,15) — рыночные лотки, точечные
препятствия (не читаются как укрытие, чисто декор-геометрия). `$`
(30,14) — pickup патронов. `>` (33,15) — выход `exit_to_plotina`.
Плаза — главный узел, из неё открываются все четыре луча.

### Зона C — Кузница/верстак Палыча, `x 36–42, y 8–26`, коридор `x33–36,y12–14`

```
y08 ######
y12 .##V..
y14 .##...
y20 .##.$.
y26 ######
```

`V` (39,15) — Виктор Павлович «Палыч». `$` (40,20) — pickup металлолома.
Здесь же — проверка `[Ремонт ≥ 6]` из `quest.svoi_truby.remont_palycha`
(диалог — не в этом документе); карта только даёт физическое место для
верстака.

### Зона D — Барак отработчиков + секрет «2207», `x 4–9, y 10–25` + `x 2–9, y 4–10`

```
y04 ##X##
y06 #X,X#      X — секретная комната (2,4)–(6,8)
y08 ##,##
y10 #.....           . — барак, x4–9,y10–25
y18 #.$...           $ (7,18) — аптечка
y25 #.....
```

Барак — общий проходной зал, без отдельного NPC (Дядя Толя физически
живёт на карте `map.paneli`, см. §7 — «Отработка» начинается здесь визитом
к Грине, но самого должника нужно ещё найти на Панелях). Секретная комната
«2207» (`world-bible.md` §2.5: «закрытый бокс с номером „2207“, который
никто не может открыть») — тупиковая ниша в северном углу барака, две
единицы лута (§5), без отдельного запирающего триггера (тот же принцип,
что секрет в `01-truba.md` §6 — тайник открыт геометрически, не квестовым
условием).

### Зона E — КПП Грини / вход, `x 16–27, y 25–31` + коридор `x20–23,y18–24`

```
y18 ..
y20 ..     mainCorridor, x20–23
y24 ..1..            1 — trigger_grinya_checkpoint (21,24)
y25 G........
y27 .........S..
y31 .........
```

`G` (21,24) — Гриня, стоит ровно в горле коридора, ведущего на плазу:
любой, кто идёт «в лоб» с юга на рынок, проходит мимо него. `S` — точка
спавна героя (по факту рынок, `findSpawnPoint` берёт центр карты — сама
плаза; вход снизу условный, «с дороги от Трубы»).

### Зона F — Обходная тропа (нелинейный путь), `x 6–9, y 25–31` + связка `x9–16,y29–31`

```
y25 ..
y29 ....
y31 ....
```

Соединяет южный вход напрямую с бараком (зона D), **минуя** радиус
триггера Грини (`trigger_grinya_checkpoint`, радиус 3 вокруг (21,24)).
Подтверждено BFS-тестом (§8): барак и секрет «2207» достижимы даже если
весь радиус КПП считать непроходимым.

## 2. Темп и чередование

Гаражи — хаб, не боевая арена: врагов на карте нет (согласовано с задачей
OF-033 — «Гаражи/Панели… скорее всего, немного или нет вовсе»; охрана
кооператива «Прогресс-2», единственный близкий по духу враг, живёт на
службе, а не воюет со своими). Чередование опирается на исследование +
диалоги, без блока дольше ~60–90 с одного типа:

| Блок | Зона | Тип темпа |
|---|---|---|
| Приход, КПП Грини | E | Диалог (квест-хук `quest.svoi_truby`) |
| Рынок, Пересказчик, лут | B | Исследование |
| Депо, Дядя Гена | A | Диалог (крючок `quest.med_dlya_semyorki`) |
| Кузница, Палыч, проверка `[Ремонт]` | C | Диалог + мини-проверка навыка |
| Барак, секрет «2207» | D | Исследование (опционально — обход через F) |

Ни один блок не предполагает бой — вся «дерзость» этой локации в диалоге
(«Отработка», OF-046), не в реалтайм-экшене; это осознанно контрастирует с
Трубой (первый бой) и Панелями (где бой всё же есть, см. `04-paneli.md`).

## 6. Секрет и нелинейный путь

**Секрет.** Бокс «2207» (зона D, `x2–6,y4–8`) — канонический объект
`world-bible.md` §2.5, «закрытый бокс… который никто не может открыть».
В этой волне трактовка — физическая: комната геометрически тупиковая и
слегка в стороне от главного барака (нужно свернуть на север от общего
прохода), без отдельного игрового замка (как и секрет `01-truba.md` §6).
Открывать «настоящий» замок этого бокса сюжетно (кто и почему) — задача
narrative-writer, если возникнет соответствующий квест; карта уже
физически резервирует место.

**Нелинейный путь.** Зона F — тропа вдоль западной стены от южного входа
прямо в барак отработчиков, минуя КПП Грини. Не «стелс» в смысле детекции
(в игре пока нет системы обнаружения NPC), а честный альтернативный
маршрут: игрок, который не хочет разговаривать с Гриней первым, может
сразу пойти к бараку/секрету и вернуться к плазе с другой стороны. Оба
маршрута подтверждены BFS-тестом (см. §8).

## 7. Связь с флагами `main-quest.md`

- Гриня физически стоит на пути «в лоб» к рынку — сюда попадает точка
  входа в квест `quest.svoi_truby` (стадия `start`, `public/data/
  quests.json`) и сцена дерзости «Отработка» (`main-quest.md` §3, флаг
  `flag.otrabotka_tolya`). Сам Дядя Толя, цель сцены, физически находится
  на `map.paneli` (см. `04-paneli.md` §7) — по `world-bible.md` §4 его
  локация «Панели», а не Гаражи; игрок получает задание здесь, решает его
  на месте, у Толи.
- Дядя Гена — крючок квеста `quest.med_dlya_semyorki` («Медь для
  семёрки»): медь нужно добыть у Бати Кота на `map.paneli` (Оголённая
  линия), физически на разных картах — согласовано.
- Палыч — точка проверки `[Ремонт ≥ 6]` (`quest.svoi_truby.remont_palycha`),
  открывающей один из двух путей к `flag.vtoraya_pravda` в Q4
  (`main-quest.md` §2, Q4). Диалог и сама сцена «Полчаса» (кульминация Q2,
  `flag.palych_pravda`) — по сюжету происходит тоже здесь, в Гаражах
  (`main-quest.md` §2, Q2) — эта карта её физически вмещает (Палыч уже
  размещён).

## 8. Читаемость и проверка по требованиям задачи

- **Нелинейный путь**: зона F, обход КПП Грини (§6).
- **Секрет**: бокс «2207» (§6).
- **Главный конфликт локации**: отработка — герой либо сдаёт Толю
  Грине, либо предупреждает его; карта физически поддерживает оба
  исхода одинаково (нет геометрии, которая делает один выбор «удобнее»).
- **История в декорациях**: депо с трамваем №7 (единственный работающий
  транспорт города, `world-bible.md` §5 «Чугунный век»), автомат с
  газировкой (пасхалка, `world-bible.md` §7), закрытый бокс «2207».
- **Чередование темпа**: см. §2 — только исследование/диалог, ни одного
  блока дольше ~90 с одного типа, боя нет вовсе (осознанно, см. §2).
- **Ширина проходов / без диагоналей**: ≥5 тайлов на всех основных
  маршрутах (плаза, депо, кузница, КПП); второстепенные ответвления к
  боксам — 2–4 тайла, но это не боевые/стелс-узкости, а хабовые тупики;
  все препятствия — прямоугольные заливки (`wallRects`), ни одной
  диагональной цепочки одиночных клеток.
- **Проверка проходимости**: `tests/unit/game/world/act1-maps.test.ts` —
  BFS от `findSpawnPoint` до каждого NPC/триггера/лута/выхода на реальном
  `public/data/maps/garazhi.json`; отдельно вручную подтверждено (см.
  отчёт задачи), что барак и секрет остаются достижимы даже при полностью
  заблокированном радиусе `trigger_grinya_checkpoint` — обход в §6 не
  бутафорский.
