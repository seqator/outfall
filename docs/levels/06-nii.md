## 0. Формат схемы

Карта **48×34 тайла**. Ось `x`: 0 (запад, обходной дюкт) → 47 (восток,
кабинет Веденеева и секретная плоттерная); ось `y`: 0 (север, архив и
плоттерная) → 33 (юг, вход/выход к Оголённой линии/Панелям). 1 символ
ASCII = 2×2 тайла. Ширина проходов ≥4 тайла на главных маршрутах,
единственное узкое место — сам охраняемый коридор (§2.А), прямое, без
диагоналей.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимая клетка |
| `.` | пол, проходимо |
| `S` | точка спавна героя (по факту — главный зал лаборатории, `findSpawnPoint` берёт центр карты, см. §7) |
| `V` | Технолог Веденеев (`npc.vedeneev`) |
| `Y` | Юрий Слепцов (`npc.yuriy_sleptsov`) |
| `t` `u` | точки спавна `enemy.avtomat_nii` (охраняемый коридор) |
| `1` | триггер `trigger_arhiv_nii` |
| `2` | триггер `trigger_plotter_easter_egg` (секрет) |
| `X` | секрет — плоттерная (шестипалые схемы) |
| `>` | выход `exit_to_paneli` |

## 1. Общая схема (1 симв. = 2×2 тайла)

Композиция: главный зал лаборатории (B) в центре, к нему с юга ведёт
**охраняемый** коридор (A, два `enemy.avtomat_nii`), с запада —
**необнаруживаемый** обходной технический дюкт (E), с севера — архив
(D), с востока — кабинет Веденеева (C) и за ним, в отдельном закутке, —
секретная плоттерная (F).

```
y00 ########################
y02 ######......######.....#   <- архив (D) слева, кабинет+плоттерная справа
y04 ######......######.....#
y06 ######......######.....#
y08 #.....................##   <- главный зал (B)
y10 #.....................##
y12 #.....................##
y14 #.....................##
y16 #................#######
y18 #................#######   <- дюкт (E, левый столбец) тянется вдоль всей карты
y20 #....####.....##########   <- охраняемый коридор (A) справа, дюкт слева
y22 #....####.....##########
y24 #....####.....##########
y26 #...............########   <- дюкт смыкается с южной площадью
y28 #...............########
y30 ########........########   <- южная площадь (вход/выход)
y32 ########........########
```

### Зона A — Охраняемый коридор, `x 19–26, y 20–27`

```
y20 ########
y21 #..t...#      t (22,21) — enemy.avtomat_nii
y23 #......#
y26 #......#
y27 #..u...#      u (22,26) — enemy.avtomat_nii
```

Прямой маршрут из южной площади в главный зал. Оба автомата — турели
(`moveSpeed 0`), стоят в открытом пространстве коридора без прикрытия за
углами — видны игроку издалека, телеграф лазера (500 мс) читается на всю
длину коридора.

### Зона B — Главный зал лаборатории, `x 10–33, y 8–19`

Культуральная лаборатория штамма-0 (декоративная привязка, без отдельной
коллизии) — `bint`-лут (20,11) и вход во все четыре крыла.

### Зона C — Кабинет Веденеева, `x 34–43, y 8–15`

`V` (38,11) — Технолог Веденеев. Путь «уболтать»
(`main-quest.md` §2 Q4 — `[Речь ≥ 6]`) физически ведёт сюда, в личный
кабинет, а не в общий зал — разговор один на один.

### Зона D — Архив, `x 12–23, y 2–7`

`1` (17,4) — `trigger_arhiv_nii`, анкер второго независимого пути к
`flag.vtoraya_pravda` («документы о Растворении… доступно без проверки
навыка — достаточно дойти до архива по сюжету», `main-quest.md` §2 Q4).

### Зона E — Обходной технический дюкт, `x 3–8, y 8–29`

Узкий (5 тайлов) затопленный служебный ход вдоль всей западной стены —
единственный маршрут из южной площади в лабораторию/архив, который **не
проходит через охраняемый коридор A**. Это физическое «обход»/«стелс»
прочтение того, что игрок может дойти до Веденеева/архива без единого
выстрела.

### Зона F — Секрет: плоттерная, `x 37–45, y 2–7`

`Y` (41,4) — Юрий Слепцов («обслуживает плоттер и архив»,
`world-bible.md` §2.7). `2` (43,5) — `trigger_plotter_easter_egg`,
канонический пасхалка-объект: «плоттер НИИ рисует всем шесть пальцев»
(`OUTFALL-CONCEPT.md` §7, единственная разрешённая мета-шутка про
нейросети). Комната — тупиковый закуток за кабинетом Веденеева, не на
пути к архиву/боевому коридору.

## 2. Темп и чередование

| Блок | Зона | Тип темпа |
|---|---|---|
| Южная площадь | — | Переход/ориентир (выбор маршрута: A или E) |
| Охраняемый коридор | A | Бой (2 турели, читаемый телеграф) |
| Главный зал | B | Исследование (хаб, лут) |
| Кабинет Веденеева | C | Диалог (ядро Q4 — поворот сюжета) |
| Архив | D | Исследование (триггер-анкер второго пути к правде) |
| Дюкт (обход) | E | Исследование/стелс (альтернатива бою) |
| Плоттерная | F | Исследование (секрет, пасхалка, диалог с Юрием) |

Игрок, выбравший коридор A, получает бой сразу после площади и дальше —
чистое исследование/диалог; игрок, выбравший дюкт E, получает
исследование без боя вовсе — оба варианта укладываются в правило «не
более 90 секунд подряд одного типа».

## 6. Секрет и нелинейный путь

**Секрет.** Плоттерная (зона F) — канонический пасхалка-объект
(«плоттер рисует всем шесть пальцев», `OUTFALL-CONCEPT.md` §7),
физически в тупиковом закутке за кабинетом Веденеева, не на пути ни
одного из основных маршрутов.

**Нелинейный путь.** Технический дюкт (зона E) — полноценный обход
охраняемого коридора A: та же цель (главный зал/архив/Веденеев)
достижима без единого боя. Это прямое физическое воплощение того, что
Q4 не требует силового прохождения — только диалог/документы.

## 7. Связь с флагами `main-quest.md`

- Веденеев (кабинет C) — центральный NPC Q4, поворотная сцена; путь
  «уболтать» физически ведёт в его личный кабинет.
- Юрий Слепцов (плоттерная F) — обслуживает архив и плоттер по
  world-bible §2.7; размещён рядом с пасхалкой, которую он же формально
  обслуживает.
- `trigger_arhiv_nii` — анкер независимого от Палыча пути к
  `flag.vtoraya_pravda` («достаточно дойти до архива по сюжету, без
  проверки навыка», `main-quest.md` §2 Q4).
- `S` — как и на остальных картах, отдельного поля точки спавна игрока
  `MapSchema` не описывает; с реальным переключением карт (OF-051,
  `demo-scene.ts: switchMap`/`resolveEntryPoint`, живая проверка —
  `tests/e2e/act2-3-transition.spec.ts`) вход с Панелей высаживает героя
  на «зеркальном» exit — `exit_to_paneli` (23,31), в южной площади перед
  развилкой A/E, а не в центре карты. `findSpawnPoint` (центр карты,
  главный зал, `(24,17)`) остаётся фолбэком только для прямого захода
  `?map=nii`.

## 8. Читаемость и проверка по требованиям задачи

- **Нелинейный путь**: технический дюкт, обход охраняемого коридора (§6).
- **Секрет**: плоттерная с пасхалкой (§6).
- **Главный конфликт локации**: силовой проход мимо охраны НИИ против
  тихого обхода — оба физически ведут к одному и тому же повороту сюжета.
- **История в декорациях**: полузатопленный корпус, культуральная
  лаборатория штамма-0, плоттер с шестипалыми схемами — до всякого
  диалога видно, что здесь тайно продолжают работу над «противоядием».
- **Чередование темпа**: см. §2.
- **Ширина проходов / без диагоналей**: ≥4 тайла на маршрутах,
  охраняемый коридор ≥5 тайлов в самом узком месте (не «коридор под
  45°» — прямой, ось x/y).
- **Проверка проходимости**: `tests/unit/game/world/act2-3-maps.test.ts`
  — BFS от спавна подтверждает достижимость Веденеева, Юрия, обоих
  спавнов турелей, обоих триггеров, лута и выхода, включая обе стороны
  развилки «коридор A / дюкт E»; живьём (реальный движок) —
  `tests/e2e/act2-3-transition.spec.ts` подтверждает переход
  Панели↔НИИ и то, что оба автомата уже заспавнены к моменту прихода
  игрока.
