## 0. Формат схемы

Карта **52×38 тайла**. Ось `x`: 0 (запад, гниющий сад и колодцы) → 51
(восток, аптека); ось `y`: 0 (север, архив) → 37 (юг, вход/выход к
Плотине). 1 символ ASCII = 2×2 тайла (кроме отмеченных крупных
close-up-врезок — 1 символ = 1 тайл). Ширина проходов ≥4 тайлов на главных
маршрутах, комнаты — прямоугольные заливки, без диагоналей.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимая клетка |
| `.` | пол, проходимо |
| `S` | точка спавна героя (по факту — купель, зал B; `findSpawnPoint` берёт центр карты, см. §7) |
| `D` | Доктор Соломин (`npc.doctor_solomin`) |
| `L` | Сестра Люба (`npc.sestra_lyuba`) |
| `F` | Дед Фрол (`npc.ded_frol`) |
| `1` | триггер `trigger_sestra_lyuba_checkpoint` |
| `2` | триггер `trigger_arhiv_sanatoriya` |
| `3` | триггер `trigger_kolodtsy_sanatoriya` (секрет) |
| `r` | точки спавна `enemy.krysa_plastikovaya` (гниющий сад) |
| `X` | секрет — колодцы за оградой |
| `>` | выход `exit_to_plotina` |

## 1. Общая схема (1 симв. = 2×2 тайла)

Композиция — «расчёска»: центральный зал-купель (B) с тремя крыльями
(архив на севере, аптека на востоке) и южным входом через КПП Сестры
Любы; вдоль всего западного края тянется гниющий сад (C), который служит
одновременно зоной исследования/боя и обходным путём из входа прямо в
архив, минуя КПП и зал.

```
y00 ##########################
y02 ##########################
y04 #.................########   <- север: архив (E) справа, сад (C) слева
y06 #.................########
y08 #.................########
y10 #.................########
y12 #.................########
y14 #.......####..############   <- корридор архив<->зал (главный маршрут)
y16 #.................#......#   <- зал-купель (B) слева, аптека (D) справа
y18 #........................#
y20 #........................#
y22 #........................#
y24 #........................#
y26 #.................########
y28 #................#########   <- КПП Сестры Любы (гейт, A)
y30 #....######....###########
y32 #....######....###########   <- вход/выход к Плотине (юг)
y34 #....######....###########
y36 #....######....###########
```

Левая колонна (`x 2–9`) на всех строках — гниющий сад (C), протянутый по
всей высоте карты: он касается и северного архива (обход), и южного
входа/КПП, и содержит нижний карман — секретные колодцы.

от прямого маршрута дверь. `2` (25,8) — `trigger_arhiv_sanatoriya`,

подсказки от Деда Фрола (диалоги — OF-036).

## 2. Темп и чередование

| Блок | Зона | Тип темпа |
|---|---|---|
| Вход, Сестра Люба | A | Диалог (КПП, квест-хук Q3 / продолжение «для колодца») |
| Зал-купель, Соломин | B | Диалог (ядро Q3 — «чудо исцеления» против физической улики) |
| Сад: Дед Фрол | C (север) | Диалог (альтернативная подсказка) |
| Сад: крысы | C (центр/юг) | Бой (рашер-свара, 4 отдельных спавна — см. §4) |
| Секрет: колодцы | C (юг) | Исследование (мрачная находка без боя) |
| Архив | E | Исследование (триггер-анкер улики) |
| Аптека | D | Исследование (лут, декоративная привязка к фракции) |

Ни один блок не тянется дольше «диалог → бой/исследование» — прямой
маршрут (вход→зал→архив) целиком без боя, боевой эпизод целиком в
стороне (сад), что даёт игроку выбор темпа: пройти мирно или завернуть в
сад за лутом и дракой.

Тематически: гниение сада (штамм-0, три года) привлекает «пластиковых»
крыс — единственный боевой эпизод карты физически завязан на ту же улику,
которую игрок ищет диалогом (окружение рассказывает то же, что скажут
NPC). **Примечание по количеству.** `EnemySpawnSchema.count` в движке пока
не влияет на число реально заспавненных врагов —
`spawnEnemiesFromMarkers`/`loadMapIntoWorld` (`src/game/demo-scene.ts`,
`src/game/world/map-loader.ts`) создают ровно одну боевую сущность на
каждый элемент `enemySpawns[]`, независимо от `count` (тот же
пре-существующий пробел движка, что и `toSpawnId` для карт, см.
`src/data/schemas/map.ts`, докстринг `MapExitSchema`). Поэтому «3–5» из
GDD реализовано четырьмя отдельными записями `enemySpawns[]`, а не полем
`count` — доведение до полноценного group-spawn по `count` вне скоупа
OF-037 (gameplay-programmer).

## 6. Секрет и нелинейный путь

**Секрет.** Колодцы за оградой (южный карман сада, зона C) — канонический
объект `world-bible.md` §2.6 («колодцы за территорией санатория — место
тайной травли „загрязнителей“»). Физически изолированы от главного
маршрута узким проходом внутри сада; находка — мрачная деталь окружения
без боя, подготавливающая почву для диалоговой развязки Q3 (продолжение
«для колодца», OF-036).

**Нелинейный путь.** Гниющий сад (зона C) целиком — обход, соединяющий
южный вход напрямую с архивом (север), минуя и КПП Сестры Любы, и
зал-купель. Игрок, который не хочет разговаривать с Чистыми (например,
после `flag.dlya_kolodtsa = otkazal` в Акте 1, испортившего репутацию),
может дойти до архивной улики полностью в обход общины — ценой встречи с
крысами вместо диалогов.

## 7. Связь с флагами `main-quest.md`

- Доктор Соломин (зал B) — центральный NPC Q3, диалог «чудо исцеления»
  против физической улики гниения; размещён в самом сердце купели.
- Сестра Люба (КПП A) — крючок продолжения «для колодца»
  (`flag.dlya_kolodtsa`) и точка невозврата №2 (мягкая, `main-quest.md`
  §4) — размещена так, что герой на прямом маршруте не может её миновать
  (в отличие от обхода через сад).
- Дед Фрол (сад C) — альтернативный путь к той же улике, что и архив
  (`[Смекалка]`/`[Медицина]` провал не блокирует сюжет, §2 Q3
  main-quest.md) — физически стоит на обходной ветке, а не на прямом
  маршруте, что соответствует его роли «запасного» источника подсказки.
- `S` — точка спавна героя не задана явно (`MapSchema` не описывает
  отдельное поле спавна игрока). На момент написания карт Акта 1
  (`03-plotina.md` §1 зона E) переключения карт в движке ещё не было, и
  единственным источником точки появления был геометрический центр карты
  (`findSpawnPoint`, BFS-фолбэк на ближайшую свободную клетку). После
  OF-051 (`demo-scene.ts: switchMap`/`resolveEntryPoint`, уже в
  репозитории) реальный вход через `exits[]` работает иначе и лучше: герой
  высаживается на позиции «зеркального» exit целевой карты — здесь это
  `exit_to_plotina` (25,36), т. е. игрок физически появляется в южном
  входе/зоне КПП, а не в центре зала — ровно та точка входа, которую
  подразумевает композиция карты (§1). `findSpawnPoint`/центр карты
  (зал-купель, `(26,19)`) остаётся только фолбэком для прямого захода
  `?map=sanatoriy` в обход графа `exits[]` (ручная проверка, без
  прохождения от Плотины) — подтверждено живым e2e
  (`tests/e2e/act2-3-transition.spec.ts`).

## 8. Читаемость и проверка по требованиям задачи

- **Нелинейный путь**: гниющий сад целиком, обход КПП/зала (§6).
- **Секрет**: колодцы за оградой (§6).
- **Главный конфликт локации**: «чудо исцеления» Соломина против
  физической улики гниения сада — прямой маршрут показывает одно
  (Соломин у купели), обходной сад показывает другое (гниющие деревья,
  крысы, колодцы) — конфликт буквально встроен в топологию карты.
- **История в декорациях**: гниющий сад на всём протяжении пути —
  единственная локация Акта 2, где штамм-0 уже физически виден игроку
  до любого диалога (`world-bible.md` «яблони гниют три года»); контраст
  с ухоженной купелью в центре.
- **Чередование темпа**: см. §2 — диалог/бой/исследование чередуются,
  ни один блок не превышает один тип дольше одного перехода между
  зонами.
- **Ширина проходов / без диагоналей**: ≥4 тайла на всех соединяющих
  коридорах, комнаты — прямоугольные заливки.
- **Проверка проходимости**: `tests/unit/game/world/act2-3-maps.test.ts`
  — BFS от точки спавна подтверждает достижимость всех NPC, всех
  спавнов крыс, всех триггеров, лута и выхода, включая обе стороны
  развилки КПП/сад; живьём (реальный движок, не только данные) —
  `tests/e2e/act2-3-transition.spec.ts` подтверждает переход
  Плотина↔Санаторий и то, что все четыре крысы уже заспавнены к моменту
  прихода игрока.
