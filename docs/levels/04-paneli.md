## 0. Формат схемы

Карта **64×36 тайла**. Ось `x`: 0 (запад, к Плотине) → 63 (восток,
периферия у колодцев Чистых); ось `y`: 0 (север) → 35 (юг). Единственная
из трёх карт волны с боевым энкаунтером — на прямой тропе Оголённой линии;
южный обход даёт честную альтернативу без боя. 1 символ ASCII = 2×2
тайла. Ширина проходов ≥5 тайлов на главных маршрутах (двор, тропа, обход,
просека), силуэты пятиэтажек — прямоугольные заливки, без диагоналей.

### Легенда

| Символ | Значение |
|---|---|
| `#` | стена / непроходимая клетка |
| `.` | пол, проходимо |
| `S` | точка спавна героя |
| `V` | Тётя Валя |
| `T` | Дядя Толя (`npc.tolya`) |
| `B` | Батя Кот |
| `R` | Тимофей Ржавый (`npc.timofey_rzhavyy`) |
| `E` | Эмиссар Чистых (`npc.emissary_chistyh`) |
| `H` | силуэт пятиэтажки (сплошная заливка, не проходимо) |
| `t` | обломок трафо-будки / завал на тропе (точечное препятствие) |
| `1` | триггер `trigger_rubilnik` |
| `2` | триггер `trigger_dlya_kolodtsa` |
| `a` `b` | точки спавна `enemy.podlineiny` (засада на тропе) |
| `X` | секрет — ниша под будками |
| `>` | выход `exit_to_plotina` |

## 1. Схема по зонам (1 симв. = 2×2 тайла)

Композиция: двор Панелей на западе (жилой, спокойный), Оголённая линия по
центру-востоку (тропа с засадой ИЛИ южный обход без боя), периферия у
колодцев Чистых на дальнем востоке (мирная, точка сцены «Для колодца»).

### Зона A — Вход (со стороны Плотины), `x 4–15, y 14–21`

```
y14 ############
y16 #>..........#
y18 #............#
y21 ############
```

`>` (4,17) — выход `exit_to_plotina`. Здесь же — точка спавна `S`
(`findSpawnPoint` берёт центр карты, который приходится на двор, зона B).

### Зона B — Двор Панелей, `x 16–33, y 8–20`

```
x16      x19  x23  x27  x31   x33
y08 ##################
y10 #....HHHHH........#
y11 #....HHHHH.V......#   V (29,11) — Тётя Валя
y12 #....HHHHH.1......#   1 — trigger_rubilnik (29,12)
y09 #.T................#   T (21,9) — Дядя Толя, у своего подъезда
y15 #.............HHHHH#
y19 #.............HHHHH#   HHHHH (27–31,15–19) — дом Тёти Вали
y20 ##################
```

`H` — два силуэта пятиэтажек (`world-bible.md` §2.4 — «пластиковые окна
растворились, вставлены лобовые стёкла „Икарусов“»): дом Толи
(`x19–23,y10–14`) и дом Тёти Вали (`x27–31,y15–19`), сплошные
непроходимые заливки — не проход насквозь, обход по двору. Доска
объявлений (декор, без коллизии) — у входа во двор, детская площадка
(декор) — южнее домов; обе не имеют отдельных данных, чисто визуальный
слой на будущее.

### Зона C — Тропа Оголённой линии (прямой путь, засада), `x 34–47, y 14–19`

```
y14 ##################
y15 #..a......t.......#   a (38,16) — spawn_podlineiny_a; t (37,16) — обломок
y17 #.....b.......t...#   b (42,17) — spawn_podlineiny_b; t (44,17) — обломок
y19 ##################
```

Прямой и короткий путь от двора к периферии, но с засадой двух
Подлинейных (контролёр — «Бросок сети», обездвиживание, `combat.md`
§2.2). Обломки `t` — точечные препятствия/укрытия, не цепочка.

### Зона D — Будки подлинейных (Батя Кот) + секрет-ниша, `x 34–47, y 2–7`, связка `x38–41,y7–14`

```
y02 ##########....##
y03 #..t.......X.X#      t (39,3)/(43,5) — трафо-будки; X (46,3-4) — секрет
y04 #.B............#      B (36,4) — Батя Кот
y07 ##########....##
```

Единственная связь с тропой — узкая перемычка `x38–41,y7–14` (южнее
будок), поэтому будки физически требуют пройти рядом с зоной засады C
(хотя необязательно вступать в бой — спавны `a`/`b` привязаны к конкретным
точкам тропы, не блокируют весь коридор). Секрет — ниша в
северо-восточном углу будок, тайник подлинейных.

### Зона E — Периферия, колодцы Чистых, `x 48–60, y 10–23`

```
y10 ##############
y12 #.........$..#     $ (50,12) — аптечка
y15 #....R.2..E..#     R (52,16) — Тимофей Ржавый; 2 — trigger_dlya_kolodtsa; E (54,16) — эмиссар Чистых
y23 ##############
```

«За оградой Санатория» в терминах `main-quest.md` §2 — сама территория
Санатория (Акт 2) сюда не входит, это именно периферия/подступы, как и
описано («доступная в Акте 1 без открытия полного хаба Санатория»). Карта
намеренно не имеет выхода дальше на восток — Санаторий как локация ещё не
построен (OF-037), а не потому что дороги нет по лору. Эмиссар Чистых
(`npc.emissary_chistyh`) стоит рядом с Тимофеем — по сценарию OF-046
(`act1-derzost.md` §2) именно он инициирует сцену «Для колодца», Тимофей
только реагирует на выбор игрока.

### Зона F — Южный обход (нелинейный путь), `x 20–55, y 24–29`, связка `x20–25,y20–24`

```
y20 ......
y24 .............................
y29 .............................
```

Длинный, безопасный маршрут от двора Панелей прямо к периферии, минуя всю
зону C (засаду). Подтверждено BFS: с полностью заблокированной зоной
тропы (`x34–47,y14–19`) периферия и Тимофей всё равно достижимы; будки
Бати Кота при этом становятся недостижимы — они завязаны именно на
прохождение рядом с тропой, что осознанно (Оголённая линия — территория
подлинейных, к ним не подойти в обход их же тропы).

## 2. Темп и чередование

Единственная из трёх карт волны с боем — соблюдён баланс: спокойный двор
(диалог/исследование) → тропа с боем (25–35 с активного боя на 2 врагов,
с запасом укладывается в правило «не более 90 с одного типа подряд») →
снова спокойная периферия (диалог). Южный обход даёт тем, кто не хочет
боя, чисто исследовательский маршрут той же протяжённости.

| Блок | Зона | Тип темпа |
|---|---|---|
| Вход, двор | A, B | Исследование + диалог (Тётя Валя, Дядя Толя) |
| Тропа ИЛИ обход | C или F | Бой (2×`enemy.podlineiny`) ИЛИ исследование |
| Будки, Батя Кот | D | Диалог (`quest.med_dlya_semyorki`) |
| Периферия, Тимофей | E | Диалог (сцена «Для колодца») |

## 6. Секрет и нелинейный путь

**Секрет.** Ниша в северо-восточном углу будок подлинейных (зона D,
`x44–47,y2–5`) — тайник, логично принадлежащий самим подлинейным (медь,
патроны). Не заперта отдельным условием, просто в стороне от прямого
прохода через будки (нужно завернуть в угол мимо Бати Кота).

**Нелинейный путь.** Зона F — южный обход всей засады Оголённой линии.
Игрок может дойти от двора Панелей до периферии, Тимофея Ржавого и
эмиссара Чистых, ни разу
не входя в радиус боевой зоны C — подтверждено BFS с полностью
заблокированной зоной тропы (§1, зона F). Будки Бати Кота при этом
намеренно недостижимы этим маршрутом — они физически часть Оголённой
линии, к ним нет входа «в обход самих себя»; это осознанное ограничение,
а не баг геометрии.

## 7. Связь с флагами `main-quest.md`

- Дядя Толя (`npc.tolya`, зона B) — цель сцены дерзости «Отработка» (флаг
  `flag.otrabotka_tolya`, квест выдан Гриней на `map.garazhi`, см.
  `02-garazhi.md` §7); по `world-bible.md` §4 его локация — именно Панели,
  здесь он физически размещён. Id `npc.tolya` (не `npc.dyadya_tolya`) взят
  ровно из готового сценария `act1-derzost.md` §1 (узел `tolya_found`), а
  не придуман заново — чтобы перенос узлов сцены в `dialogs/*.json` не
  потребовал переименования NPC.
- Тётя Валя (зона B) — цель сцены «Рубильник» (`flag.rubilnik`); щиток
  подъезда — `trigger_rubilnik`, буквально у её дома. Реплика узла
  `otklyuchil` в `act1-derzost.md` §3 — за ней.
- Батя Кот (зона D) — крючок `quest.med_dlya_semyorki` («Медь для
  семёрки», Дядя Гена ждёт медь на `map.garazhi`).
- Тимофей Ржавый (`npc.timofey_rzhavyy`, зона E) — цель сцены «Для
  колодца» (`flag.dlya_kolodtsa`). По `world-bible.md` §4 он «уже
  знакомого игроку по Трубе» — однако физически в текущем срезе
  (`public/data/maps/truba.json`) как полноценный `npc.*` он не размещён
  (только в тексте `world-bible.md`/`main-quest.md`; вне скоупа OF-033
  менять уже сданную карту `truba`). Решение level-designer: разместить
  его здесь, на периферии — это единственное физическое появление NPC с
  этим id в игре сейчас, дублирования нет, а сцена «Для колодца» по
  `main-quest.md` §3 в любом случае происходит «на периферии Плотины/
  Оголённой линии», то есть ровно в этой зоне. Id (двойное «y» на конце,
  `npc.timofey_rzhavyy`) взят из `act1-derzost.md` §2 (узел `otkazal`), не
  придуман заново.
- Эмиссар Чистых (`npc.emissary_chistyh`, зона E) — инициатор сцены «Для
  колодца» (`act1-derzost.md` §2, узел `emissary_start`); стоит рядом с
  Тимофеем, обе роли физически в одной точке карты, как и требует сцена.
- Родион, Санитар, Серёга Сачок (уже на `map.truba`) — не дублируются
  здесь, это другая карта.

## 8. Читаемость и бой — проверка по требованиям задачи

- **Укрытия/узкие места**: тропа зоны C — единственная узкая (6 тайлов)
  боевая часть карты, с двумя точечными обломками как минимальные
  укрытия; не уже правила ≥5 тайлов.
- **Взрывоопасный/точечный объект**: обломки трафо-будок (`t`) на тропе —
  декоративная помеха, не отдельная игровая сущность (как `O`-бочка в
  `01-truba.md`, тот же принцип — геометрия, не новый тип данных).
- **Высотная точка**: не введена (движок пока не поддерживает второй
  уровень высоты, тот же вывод, что в `01-truba.md` §3 про мостки).
- **Враги без индикации**: оба спавна `enemy.podlineiny` — на открытой,
  хорошо освещённой (по будущему арту) прямой тропе, видны с точки входа
  в зону C.
- **Чередование темпа**: см. §2 — бой ограничен одной зоной, окружён
  диалогом/исследованием с обеих сторон.
- **Нелинейный путь / секрет**: §6.
- **Проверка проходимости**: `tests/unit/game/world/act1-maps.test.ts` +
  ручная проверка — периферия и Тимофей достижимы с полностью
  заблокированной зоной засады; будки Бати Кота — только через тропу
  (осознанно, см. §6).
