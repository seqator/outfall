# UI «Щиток» — макеты 5 экранов

> Задача OF-013. Владелец: `art-director`. Источники: `docs/art/art-bible.md` §5 (принято ранее, здесь — детализация), `docs/design/rpg-system.md` (КОСТЯК/навыки/перки), `docs/design/combat.md` (оружие/враги для HUD), `docs/OUTFALL-CONCEPT.md` §4–5.
> `docs/design/items-economy.md` (OF-007) на момент написания — **todo**. Поля инвентаря ниже — предварительные, основаны на весе `20 + 5×Каркас` из `rpg-system.md` §1.1 и лут-правиле «каша через час» из концепта §4. Как только OF-007 закроется, слоты и поля предмета сверяются с `ItemSchema` и при расхождении правятся здесь без спора — это todo-пометка, не блокер приёмки OF-013.

**Жёсткий запрет.** Ни один экран не должен читаться как браслет-компьютер/наручный терминал: НИ на руке персонажа, НИ как предмет, который «надевают» и смотрят на запястье. Референс всегда — стационарный или нагрудный предмет советской промышленной эстетики: электрощиток, пульт ДСП, папка «личное дело», бумажный планшет с зажимом. Диалоговый портрет и инвентарь — это панель на экране, а не устройство в мире игры. Это правило проверяется отдельным пунктом в `docs/art/checklist.md` при генерации UI-ассетов.

## 1. Сетка и масштаб

- Базовая единица разметки — **8 px** (native, ×1), всё выравнивается по сетке 8 px: отступы, высоты строк, размеры иконок кратны 8.
- Экранный масштаб — целочисленный: **×2 на 1080p, ×3 на 1440p** (см. `art-bible.md` §5), верстка считается от углов и краёв экрана (anchor top/bottom/left/right), не от центра — при смене разрешения панели не «плывут», а перескакивают между двумя фиксированными раскладками.
- Pixi-HUD (игровой, поверх канваса): целочисленный масштаб спрайтов по бакету разрешения (1080p → ×2, 1440p → ×3, промежуточные — округление вниз до целого множителя + letterbox, без билинейной фильтрации).
- DOM-UI (инвентарь, диалог, персонаж, пауза): корневой контейнер в `rem`, где `1rem = 8px × масштаб_бакета`; расстояния и размеры иконок заданы в `rem`, поэтому переход 1080p → 1440p не требует отдельной вёрстки, только смены бакета.
- Все размеры ниже указаны **at ×2 (референс 1920×1080)**; для 1440p — умножать на 1,5 (переход к ×3).

## 4. Экран 1 — HUD (игровой, Pixi, поверх канваса)

Всегда на экране во время игры на карте и в бою. Ничего не блокирует ввод.

```
0,0 ────────────────────────────── 1920,0
│                                        │
│              игровое поле              │
│                                        │
│  ▲ hostile-red HP-полоска 48×4 над     │
│    головой врага — только в бою        │
│                                        │
├──────────────────────────────────────┤ y=984
│ [МАНОМЕТР]  [ЛАМПА]   [ОРУЖИЕ/ЖАР]   [РЫВОК] [1][2][3][4]  ┃ ЖУРНАЛ 2 строки ┃│
│  Ø96px       Ø32px      96×96 + текст  Ø48    32×32×4       320×80           │
└──────────────────────────────────────┘ y=1080, панель 1920×96
```

| Зона | Размер (at ×2) | Содержимое | Данные |
|---|---|---|---|
| Манометр здоровья | круг Ø96, стрелка + дуговая шкала | Текущее/макс. ХП | `ХП = 40+8×Каркас` (rpg-system §1.1); дуга зелёная → жёлтая <50% → красная <30%, пульс 0,5 Гц |
| Лампа радиации/химии | круг Ø32 | Индикатор нахождения в токсичной зоне | горит `toxic-teal`/зелёным при уроне по времени, погашена вне зоны |
| Слот оружия + патроны/жар | 96×96 иконка + янтарный дисплей `NN/NN` | Иконка текущего оружия, магазин/резерв (напр. «Огрызок» 8/24) | из `combat.md` §3; для «Дуги» дисплей заменяется горизонтальной шкалой Жара 0–100 |
| Индикатор рывка | круг Ø48, заполнение по дуге | Кулдаун рывка | `ОткатРывка = 0,8 с` фиксирован (combat.md §4.4), заполняется 0→100% |
| Хоткеи 1–4 | 4×(32×32) тумблеры | Быстрые предметы/гранаты/аптечка | подписаны цифрой, иконка предмета |
| Журнал событий | 320×80, 2 строки моно 8×12 | Последние события: подбор, урон, статус | текст «печатается» слева, старая строка уезжает вверх и гаснет за 400 мс |
| Статус «Шок» | иконка 32×32 у манометра, появляется по триггеру | Мигающий янтарный значок + лёгкая красная виньетка по краям экрана | ровно 4,000 с (combat.md §4.6), исчезает без анимации затухания — таймер точный |

**Состояния**
- Манометр: норма (фосфор-зелёная дуга) / предупреждение (янтарь, <50%) / критично (`hostile-red`, пульс 0,5 Гц, <30%).
- Тумблер хоткея: пусто (тёмная ниша `soot`, нет иконки) / назначено-неактивно (`panel`, иконка) / активно на кулдауне (иконка затемнена на 50%, тонкая дуга кулдауна) / нажато (вспышка `flash-white` 100 мс) / недоступно (нет ресурса — иконка красная рамка `hostile-red`).
- HP-полоска врага: скрыта вне боя → появление 150 мс fade-in при получении/нанесении урона → исчезает через 3 с без урона (200 мс fade-out).

**Переходы.** Смена оружия — иконка слота меняется мгновенно (без анимации иконки, только рамка мигает `flash-white` 1 кадр); появление журнальной строки — сдвиг+fade 150 мс; манометр не анимируется плавно между значениями (мгновенный, «честный» показ, как счётчик — соответствует духу «Щитка»), только цвет дуги переходит за 200 мс.

## 5. Экран 2 — Инвентарь (DOM-UI, полноэкранный)

Открывается по клавише (Tab/I), игра ставится на паузу локально (симуляция не тикает), фон приглушается на 60%.

```
┌─ РАМКА МЕТАЛЛ, скол rust по углам, 16px толщина ───────────────┐
│ ЛИЧНЫЕ ВЕЩИ                                    ВЕС: 34,2 / 45 кг│ ← H1 + весы
├───────────────┬───────────────────────────────┬────────────────┤
│  СИЛУЭТ        │  ИНВЕНТАРЬ 8×6 ЯЧЕЕК           │  ОПИСАНИЕ       │
│  96×192        │  [ ][ ][ ][ ][ ][ ][ ][ ]       │  (янтарный      │
│  ┌──┐ Голова   │  [ ][█][ ][ ][ ][ ][ ][ ]       │   дисплей)      │
│  │  │ Тело     │  [ ][ ][ ][ ][ ][ ][ ][ ]       │  печать         │
│  │  │ Рюкзак   │  [ ][ ][ ][ ][ ][ ][ ][ ]       │  посимвольно    │
│  │  │ Пояс×2   │  [ ][ ][ ][ ][ ][ ][ ][ ]       │  320×420        │
│  └──┘ Оружие×2 │  [ ][ ][ ][ ][ ][ ][ ][ ]       │                 │
│  Обувь         │  ячейка 48×48 (×2=96×96)        │                 │
└───────────────┴───────────────────────────────┴────────────────┘
```

Общий размер 1920×1080, три колонки: 480 / 960 / 480.

| Зона | Данные | Примечание |
|---|---|---|
| Силуэт со слотами | иконки-«чертёж» пунктиром на местах: Голова, Тело, Рюкзак/спина, Пояс×2 (быстрый доступ), Оружие в руке×2, Обувь | список слотов предварительный — TODO сверить с `items-economy.md` (OF-007) |
| Сетка предметов | 8×6 = 48 ячеек, 48 px (×2=96) каждая, drag-and-drop | стек-предметы (патроны, детали) — счётчик янтарём в правом нижнем углу ячейки |
| Весы (шкала веса) | балка-качели, левая чаша заполняется по `Вес_тек/Вес_лимит` | `Вес_лимит = 20+5×Каркас` (rpg-system §1.1); TODO: вес конкретных предметов из OF-007 |
| Панель описания | название, тип, вес, цена (модификатор Языка не показывается тут — только базовая), эффект | у предметов с лут-правилом «каша через час» (концепт §4) — иконка песочных часов + обратный отсчёт, тикает только на карте, не в меню |

**Состояния ячейки**
- Пустая — тёмная ниша `soot`, без обводки.
- Занята — иконка 32×32 + 1px обводка `soot`, счётчик стека при N>1.
- Hover — обводка `flash-white`, всплывает тултип (мелкий шрифт 8×10) через 300 мс.
- Перетаскивание — иконка следует за курсором с 50% прозрачностью, ячейка-цель подсвечена пунктиром `acid` (единственное применение acid вне паузы — как «активная зона», обосновано высокой заметностью при быстром драг-н-дропе).
- Заблокирован слот экипировки (например, тяжёлая броня при Каркас < требования) — перечёркнут диагональю `rust`, тултип с требованием.
- Перегруз (вес > лимита) — весы наклонены в красную зону, вся панель веса мигает `hostile-red` 0,5 Гц, текст «Перегруз: −20% скорость» (формула rpg-system §1.1).

**Переходы.** Открытие/закрытие — «дверца щитка» разворачивается по вертикали от нижней панели HUD за 200 мс (ease-out), фон достаёт blur/dim за то же время. Перенос предмета в ячейку — snap за 80 мс, короткая вспышка `flash-white` на принявшей ячейке.

## 6. Экран 3 — Диалог (DOM-UI, нижние 40% экрана)

Игра не останавливается визуально (мир виден в верхних 60%, статичен), поверх — металлический короб.

```
──────────────────────────────────── y=648 (60% высоты)
│         игровой мир виден            │
├──────────────────────────────────────┤ y=648
│ ┌────────┐  ПАЛЫЧ                    │ ← имя, трафарет H2
│ │ ПОРТРЕТ│  ┃ «На полчаса сказали.   │ ← тело, моно 8×12,
│ │ 96×96  │  ┃  Тридцать лет как.»    │   фосфор, максимум 2 строки
│ │ (×2=   │  ├────────────────────────┤
│ │ 192×192│  │ 1. [Язык 6] Расспросить│ ← варианты, warning-yellow
│ │ 3 эмоции│ │ 2. Промолчать          │   если проверка проходима
│ └────────┘ │ 3. [Смекалка 8] ~~Найти│ ← провальная: серый,
│             │    слабое место~~      │   зачёркнут
└────────────────────────────────────┘ y=1080
```

| Зона | Размер | Данные |
|---|---|---|
| Портрет | 192×192 (×2), рамка с заклёпками + именная табличка снизу | 3 эмоции (нейтраль/зол/дружелюбно), смена — мгновенная (без морфинга, честный «щёлк» кадра) |
| Реплика | ширина ~1400, до 2 строк, моно 8×12 фосфор | текст печатается по символу, ~30 симв/с; клик/пробел — доскроллить до конца мгновенно |
| Варианты ответа | 1–5 строк, нумерованные метал-бирки | проверки `[Навык N]` — `warning-yellow`, если порог проходим сейчас; провальные — серый (`panel` затемнённый) и зачёркнуты, но видимы (честность порога — rpg-system §1: игрок видит требование заранее) |

**Состояния варианта ответа**
- Обычный — текст фосфор/янтарь на тёмном металле.
- Hover / выбор стрелками — подложка-полоса `panel`→ подсвечена, префикс `>` мигает.
- Выбран/подтверждён — вспышка `flash-white` 100 мс, затем переход к следующей реплике.
- Недоступен (провал проверки) — серый, зачёркнут, курсор не меняется на «клик», клик по нему ничего не делает.

**Переходы.** Короб выезжает снизу за 200 мс при входе в диалог, съезжает вниз за 150 мс при выходе; смена реплики — без анимации текста, кроме печати по символу; смена эмоции портрета — 1 кадр, без кроссфейда (плоская смена — в духе «честного» терминала, не мимики).

## 7. Экран 4 — Персонаж («Личное дело»)

Открывается по клавише (C) или автоматически на уровне-апе (перк/распределение очков). Полноэкранный DOM-UI, стилизован под канцелярскую папку на металлическом планшете-зажиме.

│                │  Твёрдость●●●●●○○○○○ 5 │  ...                 │

| Зона | Размер | Данные |
|---|---|---|
| Портрет + имя | 192×192, подпись под ним | статичный портрет игрока, имя настраиваемое |
| КОСТЯК | 6 строк-тумблеров, каждая — рычажок + ряд из 10 лампочек (Ø8px, ×2=16) | значение 1–10, зажжённые лампочки = фосфор-зелёные, незажжённые — тёмные ниши; цифра справа янтарём |
| Навыки | список 10 строк, полоса-шкала 160×16 (×2), % справа | коронные (3 стартовых) отмечены значком ★ `acid`-подложка не используется — звезда цветом `terminal-amber`, чтобы не плодить acid-акценты |
| Перки | ряд «штампов» по слотам уровня 2/4/6/8/10/12/14 | круглый штамп 64×64: получен — оттиск `hostile-red`/`poster-red-faded` с текстом перка; доступен к выбору сейчас — пунктирный контур `acid`, мигает 0,5 Гц (единственное doступное здесь применение acid, при выборе на уровне-апе); ещё не открыт — пустой пунктир `panel`, тултип с условием |

**Состояния**
- Тумблер КОСТЯК: только для чтения вне создания персонажа/левел-апа; во время распределения очков — рычаг кликабелен, hover подсвечивает лампочку-кандидата `flash-white`, «потратить» — лампочка зажигается с коротким миганием.
- Навык: обычный (полоса фосфор) / кэп 100 (полоса золотая рамка `terminal-amber`, дальше не растёт — UI блокирует трату очков сверх кэпа, rpg-system §2).
- Перк-штамп: получен (статичный оттиск) / доступен-выбираемый (пульсирующий контур, клик открывает подтверждение) / заблокирован по требованию (серый пунктир, неактивен, тултип с недостающим условием) / заблокирован по занятому слоту (слот уже занят другим перком в этом уровне — штамп скрыт, показан только выбранный).

**Переходы.** Открытие — «страницы папки» листаются слева направо за 250 мс (parallax 2 слоя: обложка/лист); выбор перка — штамп «впечатывается» за 150 мс (масштаб 1.3→1.0 + вспышка `flash-white` 1 кадр, звук удара штампа — зона audio-designer).

## 8. Экран 5 — Пауза

Простейший экран, минимум элементов, максимум атмосферы «умирающего терминала».

```
┌──────────────────────────────────────────────┐
│  фон игры затемнён на 80%, лёгкая desaturate  │
│                                                │
│              ┌──────────────────┐             │
│              │   ПАУЗА          │ ← H1 трафарет
│              │                  │
│              │  > Продолжить    │ ← hover: янтарь фон-полоса
│              │    Сохранить     │
│              │    Загрузить     │
│              │    Настройки     │
│              │    Выйти         │
│              │                  │
│              │  _               │ ← мигающий курсор
│              └──────────────────┘
│  Собрано агентами и нейросетями. Честно.       │ ← мелкий текст,
└──────────────────────────────────────────────┘   единственная строка,
                                              1 раз за игру видна здесь
```

Терминал-панель 480×360 (×2), центр экрана (единственный экран с центральной версткой — намеренное исключение, пауза читается как «всё замерло»), поверх — статичные линии CRT-развёртки (не мерцают, чтобы не раздражать; опция отключения в «Настройках»).

| Пункт | Состояние |
|---|---|
| Продолжить | всегда активен |
| Сохранить | disabled (серый, без `>`) во время активного боя/шока — таймер лута и бой не должны сохраняться в неконсистентном моменте |
| Загрузить | disabled, если нет сохранений |
| Настройки | всегда активен |
| Выйти | всегда активен, требует подтверждения (второй клик/Enter) |

**Состояния пункта.** normal (фосфор-зелёный текст) / hover-keyboard (полоса-подложка `terminal-amber` 20% непрозрачности + префикс `>` статичен, не мигает — мигает только общий курсор `_` внизу списка) / disabled (текст `panel`, приглушён, курсор не встаёт) / pressed (вспышка `flash-white` 1 кадр перед действием).

**Переходы.** Вход в паузу — экран «гаснет» как ЭЛТ (2 кадра: сжатие по вертикали в линию → вспышка → пусто, затем терминал «включается» тем же путём в обратном порядке), суммарно 200 мс; выход — зеркально. Строка про нейросети не анимируется отдельно, она статична и мелкая (мета-шутка ровно одна на игру — правило концепта §7, здесь единственное место её показа как fallback-текста, если титры пропущены).

## 9. Сводка

1. 5 макетов — HUD (Pixi), Инвентарь/Диалог/Персонаж/Пауза (DOM) — с ASCII-раскладкой, размерами at ×2 и данными из `rpg-system.md`/`combat.md`.
2. Шрифт — два кастомных битмап-семейства («Щиток Трафарет» для заголовков, «Щиток Моно» для тела/мелкого текста) с веб-фолбэками; минимум 16 px после масштабирования соблюдён везде.
3. Сетка 8 px native, целочисленный масштаб ×2/×3 по бакету разрешения, верстка от краёв экрана — без «плывущих» панелей между 1080p и 1440p.
4. Состояния кнопок/ячеек/тумблеров описаны для каждого экрана: normal / hover / active / disabled / pressed, плюс специфичные (перегруз, шок, проваленная проверка, доступный перк).
5. Палитра — 14 цветов из 40 назначены конкретным ролям UI; `acid` использован намеренно скупо (только драг-н-дроп ячейка и доступный перк) — не превращаем «Щиток» в «нейрослоп»-неон.
6. Ни один экран не содержит браслета/наручного устройства — все интерфейсы физически стационарны (щиток, папка, терминал на столе).
