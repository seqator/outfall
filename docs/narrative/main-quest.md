# OUTFALL — Главный квест (структура по актам, точки выбора, концовки)

> Задача OF-008. Автор: narrative-writer. Источники: `docs/narrative/world-bible.md` (авторитетный источник фактов — используется без изменений), `docs/OUTFALL-CONCEPT.md` §4, `docs/planerka/01-concept/review-duxa-simulator.md`.
> Это не документ диалогов и не GDD. Здесь — скелет сюжета, точки выбора с проверяемыми условиями и карта необратимых развилок. Полный текст диалогов и реплик — отдельные задачи (OF-024, OF-032, OF-036, OF-046). Числа боя, инвентаря и перков не проектируются здесь — они в `docs/design/`.
> Флаги и пороги репутации ниже — **условное обозначение для нарративной логики**, не финальная схема данных. Точный формат (`QuestSchema`, `ReputationSchema`) проектирует engine-architect в OF-009; значения порогов может скорректировать game-designer при балансировке — сюжетная логика (что вообще проверяется и на что влияет) от этого не меняется.

## 0. Условные обозначения

### 0.1 Репутация фракций

Три независимые шкалы, каждая условно `-100…+100`, старт `0`: `rep.progress2` (Прогресс-2), `rep.energosbyt` (Энергосбыт), `rep.chistye` (Чистые). Пороги, используемые ниже:

| Диапазон | Статус |
|---|---|
| `≥ 60` | Свои — фракция доверяет, открыт финальный квест лояльности |
| `20…59` | Норм — обычная торговля и квесты |
| `-19…19` | Нейтрально |
| `-59…-20` | Не доверяют — цены хуже, часть квестов закрыта |
| `≤ -60` | Враги — территория враждебна, финальный квест лояльности недоступен |

### 0.2 Флаги (заполняются по ходу сюжета)

| Флаг | Значения | Устанавливается |
|---|---|---|

## 2. Шесть основных квестов

### Q1. «Свои трубы» — Акт 1, Гаражи

**Цель.** Герой закрепляется в кооперативе «Прогресс-2»: чинит первое снаряжение, знакомится с Палычем и Гриней, получает первое задание кооператива.

**Ключевые NPC.** Виктор Павлович «Палыч», Гриня (Григорий), Дядя Толя, Пересказчик, Дядя Гена.

**Точки выбора.**
- **Долг Дяди Толи.** Гриня просит найти должника кооператива и привести его на «отработку». Игрок может выполнить (→ `flag.otrabotka_tolya = sdal`, `rep.progress2 +15`) или отказать/предупредить Толю (→ `flag.otrabotka_tolya = otkazal`, `rep.progress2 -5`, Толя становится доступным NPC-союзником позже). **Точка встраивания сцены дерзости 1 «Отработка».**
- **Проверка `[Ремонт]` у Палыча.** Если игрок помогает Палычу в депо и проходит `[Ремонт ≥ 6]`, открывается один из двух путей к `flag.vtoraya_pravda` (см. Q4) — Палыч случайно обмолвится о старом наряде на задвижку.

**Как меняет карту/фракции.** `rep.progress2` растёт базово за счёт участия героя в жизни Гаражей. Если `flag.otrabotka_tolya = sdal`, в депо появляется NPC «Толя-отработчик» — молчаливый, при следующих визитах отпускает всё более горькие реплики. Трамвай №7 и рынок Гаражей — доступны как хаб с этого квеста и до конца игры.

---

### Q2. «Ключ Тарифницы» — Акт 1, Плотина / Панели / Оголённая линия

**Цель.** Герой доставляет (или не доставляет) латунный ключ из пролога на Плотину, знакомится с Зоей «Тарифницей» и Энергосбытом, попадает в орбиту двух оставшихся сцен дерзости, и в кульминации акта узнаёт правду о задвижке от Палыча.

**Ключевые NPC.** Зоя Ильинична «Тарифница», Модест Бусыгин, Клавдия Бусыгина, Родион «Ключик» Углов, Батя Кот, Тётя Валя, Тимофей Ржавый.

**Точки выбора.**
- **Судьба ключа/Родиона** (наследует `flag.prolog_vybor`). Если `spas` или `oba` — Родион на Плотине становится союзником, `rep.energosbyt +10`. Если `klyuch` — Зоя прямо спрашивает «где Родион?», доступна проверка `[Язык ≥ 5]` соврать без потери репутации; провал → `rep.energosbyt -10`.
- **Рубильник на Панелях.** Модест Бусыгин просит героя лично отключить подъездный щиток должников зимой. Согласие → `flag.rubilnik = otklyuchil`, `rep.energosbyt +15`, `rep.progress2 -10` (Панели физически теряют свет — правки на карте: тёмные окна, NPC Тётя Валя переезжает к соседям). Отказ → `flag.rubilnik = otkazal`, `rep.energosbyt -10`, Бусыгин делает это сам, но без участия героя. **Точка встраивания сцены дерзости 3 «Рубильник».**
- **«Для колодца».** На периферии Плотины/Оголённой линии герой встречает эмиссара Чистых, который просит доставить Тимофея Ржавого (уже знакомого игроку по Трубе) «на очищение» к колодцам за оградой Санатория — это выездная точка Чистых, доступная в Акте 1 без открытия полного хаба Санатория. Согласие → `flag.dlya_kolodtsa = privel`, `rep.chistye +15`, лавка Тимофея в Трубе закрывается насовсем. Отказ/предупреждение Тимофея → `flag.dlya_kolodtsa = otkazal`, `rep.chistye -10`, Тимофей дарит скидку до конца игры. **Точка встраивания сцены дерзости 2 «Для колодца».**
- **Кульминация акта — «Полчаса».** По возвращении в Гаражи (после того как открыт хотя бы один источник первой правды — авто-триггер по сюжету, не требует доп. условий) Палыч сам признаётся: приказ был его, задвижку заклинило, «я кран». Устанавливает `flag.palych_pravda = true`. У игрока есть право убить Палыча на месте, без экрана подтверждения: выбор → `flag.palych_ubit = true`, `rep.progress2` обнуляется и заменяется враждой к герою лично (Гриня занимает место председателя), квест-линия Прогресс-2 в Акте 3 закрывается. Отказ от убийства → `flag.palych_ubit = false`, Палыч остаётся председателем, но подавлен до конца игры.

**Как меняет карту/фракции.** «Рубильник» и «Для колодца» физически меняют облик Панелей и Трубы (тёмные окна / закрытая лавка) — игрок видит последствия своих действий на карте до финала, а не только в цифрах. «Полчаса» — точка невозврата №1 (см. §4): дальше игра знает, что герой знает первую половину правды.

## 2.1 Три фракционных квеста Акта 1 (дополнение OF-032)

> Автор: narrative-writer, задача OF-032. Q1/Q2 выше уже были специфицированы в OF-008; эти три квеста не были явно названы в исходном OF-008 (см. §6 «Что дальше» исходной версии — «квесты Акта 1 в JSON (Q1, Q2 + фракционные) — OF-032») и спроектированы здесь по тому же принципу: расширяют уже названных NPC/локации Акта 1, не вводят новых фракций. Полные `QuestSchema`-определения — `public/data/quests.json`.

### F1. «Медь для семёрки» — Гаражи / Оголённая линия

**Цель.** Дядя Гена (машинист трамвая №7, world-bible §4) не может починить трамвай без медного провода — единственный источник меди в городе физически лежит под Оголённой линией, на территории Бати Кота и «подлинейных».

**Ключевые NPC.** Дядя Гена, Батя Кот.

**Точка выбора.** Выменять медь у Бати Кота честно (`flag.med_semyorki = vymenyal`, `rep.progress2 +10`) или срезать провода с рабочей линии самому, не спрашивая (`flag.med_semyorki = sorval`, `rep.progress2 +10`, `rep.energosbyt −15` — Энергосбыт формально контролирует Оголённую линию, world-bible §3.2, и считает самовольный демонтаж проводов кражей).

**Открывается** после завершения `quest.svoi_truby` (стадия `done`) — трамвай №7 уже признан хабом Акта 1.

### F2. «Толя: что дальше» — Гаражи / Панели

**Цель.** Продолжение судьбы Дяди Толи после сцены дерзости «Отработка» (OF-046) — расходится на две пары исходов в зависимости от того, что игрок выбрал в Q1.

**Ключевые NPC.** Дядя Толя, Гриня (упоминается).

**Точки выбора.**
- Если `flag.otrabotka_tolya = sdal`: похлопотать перед Гриней о сокращении срока отработки (`flag.tolya_ishod = oblegchil`, `rep.progress2 −5` — кооперативу не нравится мягкотелость) или не вмешиваться (`flag.tolya_ishod = ostavil`, `rep.progress2 +5`).
- Если `flag.otrabotka_tolya = otkazal`: свободный Толя предлагает возить контрабанду в обход тарифов кооператива — принять (`flag.tolya_ishod = prinyal_kontrabandu`, `rep.progress2 −10`) или отказаться (`flag.tolya_ishod = otkazal_kontrabandu`, `rep.progress2 +5`).

### F3. «Счётчик и совесть» — Плотина / Панели

**Цель.** После «Рубильника» (любой исход) Клавдия Бусыгина — старшая сестра больницы при Плотине и жена Модеста (world-bible §4) — тайно ищет того, кто поможет Панелям пережить отключение, не спрашивая мужа.

**Ключевые NPC.** Клавдия Бусыгина (упоминается Модест Бусыгин).

**Точка выбора.** Пронести лекарства и одеяла в тёмные подъезды (`flag.schetchik_sovest = pomog`, `rep.energosbyt −10`, награда `item.cons_bint ×2`) или отказаться — «тариф есть тариф» (`flag.schetchik_sovest = otkazal`, `rep.energosbyt +10`).

**Открывается** после разрешения стадии `rubilnik_otklyuchil` или `rubilnik_otkazal` квеста `quest.klyuch_tarifnicy` — сцена работает как послесловие «Рубильника» независимо от того, кто его дёрнул.

### Q3. «Святая вода» — Акт 2, Санаторий «Волна»

**Цель.** Полный хаб Санатория открывается. Герой знакомится с доктором Соломиным и сестрой Любой, видит гниющий сад, набирает первые улики против «святой воды».

**Ключевые NPC.** Доктор Соломин, Сестра Люба, Дед Фрол.

**Точки выбора.**
- **Гниющий сад.** Проверка `[Смекалка ≥ 5]` или `[Медицина ≥ 5]` позволяет герою понять, что гниение сада не связано с погодой, как утверждает Соломин, — открывает доступ к архиву Санатория и подсказку «спроси в НИИ, чем поливают купель». Провал не блокирует сюжет — Дед Фрол в разговоре о «чуде исцеления» случайно даёт ту же зацепку другим путём.
- **Позиция по травле колодцев.** Если ранее `flag.dlya_kolodtsa = privel`, Сестра Люба предлагает герою продолжить помогать с «очищением» — принять предложение даёт `rep.chistye +10`, но окончательно закрывает мирный путь примирения Прогресс-2 и Чистых (см. §4, точка невозврата №2). Отказ не отменяет уже случившееся в Акте 1, но останавливает эскалацию.

**Как меняет карту/фракции.** Начиная с этого квеста Санаторий действует как полноценный хаб Акта 2 (аптека, архив, купель доступны для взаимодействия). Репутация с Чистыми, накопленная в Акте 1 через «Для колодца», здесь получает первую сюжетную развилку.

### Q4. «Шесть пальцев» — Акт 2, НИИ «Биосток» — ПОВОРОТ

**Цель.** Герой проникает в НИИ, встречает Веденеева и лаборанта Юрия Слепцова, получает архивные документы и узнаёт вторую половину правды. Это структурный поворот игры.

**Ключевые NPC.** Технолог Веденеев, Юрий Слепцов.

**Точки выбора.**
- **Второй шаг правды (двумя независимыми путями, согласно требованию duxa-simulator).** `flag.vtoraya_pravda` устанавливается в `remont`, если ранее в Q1 пройдена `[Ремонт ≥ 6]` у Палыча; в `arhiv`, если герой лично находит документы в архиве НИИ (доступно без проверки навыка — достаточно дойти до архива по сюжету); в `oba`, если выполнены оба условия. Итог один и тот же по содержанию: приказ об открытии задвижки в Р-0 отдал Илья Матвеевич Тарасов, директор ГЭС, — отец Зои.
- **Разговор с Веденеевым о штамм-0.** Веденеев не скрывает: купель Санатория три года получает штамм-0 без ведома общины. Проверка `[Речь ≥ 6]` или `[Взлом ≥ 6]` (взломать архив лаборатории вместо разговора) даёт герою данные о риске 30 % без искажений от самого Веденеева. Устанавливает `flag.shtamm0_pravda = true` в любом случае — разница только в том, узнаёт ли герой точную цифру риска от самого автора или из документов.
- **Судьба Веденеева в этой сцене.** Герой может напасть на Веденеева здесь же (боевой исход) или уйти с информацией, оставив его работать дальше. Прямое нападение с летальным исходом → `flag.vedeneev_sudba = mertv` (лаборатория без хозяина, часть данных о штамм-0 недоступна впредь). Уход → `flag.vedeneev_sudba = zhiv`, Веденеев позже фигурирует в Акте 3 как переменная сторона (может быть привлечён к финалу Энергосбытом).

**Как меняет карту/фракции.** С этого момента НИИ доступен как локация Акта 2 наравне с Санаторием. `flag.shtamm0_pravda = true` открывает Акт 3 — это структурная точка невозврата №2.

### Q5. «Кому качать» — Акт 3, город целиком

**Цель.** Герой возвращается по трём фракциям с уже известной правдой, обсуждает будущее Трубы и Плотины с каждым лидером и приносит окончательную присягу одной стороне (либо отказывается от всех).

**Ключевые NPC.** Палыч (если жив), Зоя Ильинична, Доктор Соломин.

**Точки выбора.**
- **Присяга.** Игрок явно выбирает `flag.storona` в финальном разговоре с одним из трёх лидеров. Присяга фракции доступна только если её репутация `≥ 40` на момент разговора (иначе лидер прямо отказывает, реплика «Ты нам не свой» — навязанное ограничение, не молчаливый лок). Если ни одна репутация не достигает 40, либо игрок сознательно уходит от всех трёх — `flag.storona = neytralitet`.
- **Развилка Энергосбыта.** Если игрок присягает Энергосбыту, здесь же (или в начале Q6, в зависимости от темпа сцены) закладывается предварительный выбор `flag.energosbyt_final` (`polny_sbros` — полностью открыть Трубу и раздать штамм-0 наружу, или `dozirovka` — оставить контроль дозированным по тарифу). Этот подфлаг фиксируется здесь, но физически исполняется в Q6.

**Как меняет карту/фракции.** `flag.storona` закрывает финальные квестовые линии двух других фракций — территории, принадлежащие им, становятся недоступны для дальнейших фракционных заданий (сюжетно — герой выбрал сторону, ему больше не доверяют). Это точка невозврата №3.

### Q6. «Труба» (финал) — Акт 3, Плотина → Труба

**Цель.** Финальная сцена у главной задвижки. Герой исполняет решение, вытекающее из `flag.storona`, `flag.energosbyt_final` и (при особом условии) низкого интеллекта — см. §3 «Концовки».

**Ключевые NPC.** Зависит от `flag.storona`: Палыч/Гриня, Зоя, Соломин; Веденеев (если `flag.vedeneev_sudba ≠ mertv`) может появиться как участник или противник сцены в зависимости от стороны игрока.

**Точки выбора.** Финальное действие с Трубой/Плотиной, устанавливающее `flag.truba_deystviye` — единственный флаг, напрямую определяющий, какая из пяти концовок наступает. Подробные условия — §3.

**Как меняет карту/фракции.** Это последняя развилка игры — после неё идут слайды эпилога по шести локациям (Труба не входит в слайды эпилода как отдельная локация, так как её судьба и есть сама концовка).

## 4. Карта точек невозврата и развилок

Текстовая схема — от пролога к финалу. Стрелки `⇒` — необратимый переход (точка невозврата), `→` — обычный переход, `[...]` — развилка с несколькими исходящими путями.

```
ПРОЛОГ «Труба»
  [Выбор под водой: spas / klyuch / oba] → flag.prolog_vybor
  ⇒ ТОЧКА НЕВОЗВРАТА 0: выбор пролога нельзя переиграть внутри одного прохождения
        │
        ▼
АКТ 1
  Q1 «Свои трубы» (Гаражи)
   [Отработка: sdal / otkazal] → flag.otrabotka_tolya
   [Ремонт у Палыча пройден? да/нет] → полу-флаг для Q4
        │
        ▼
  Q2 «Ключ Тарифницы» (Плотина / Панели / Оголённая линия)
   [Судьба ключа реагирует на flag.prolog_vybor]
   [Рубильник: otklyuchil / otkazal] → flag.rubilnik
   [Для колодца: privel / otkazal] → flag.dlya_kolodtsa
        │
        ▼
   Кульминация «Полчаса»: flag.palych_pravda = true
   [Убить Палыча? да/нет] → flag.palych_ubit
   ⇒ ТОЧКА НЕВОЗВРАТА 1: герой знает первую половину правды;
      если flag.palych_ubit = true — фракционная линия Прогресс-2
      в Акте 3 закрывается навсегда (Гриня — новый председатель,
      присяга Прогресс-2 в Q5 недоступна)
        │
        ▼
АКТ 2
  Q3 «Святая вода» (Санаторий)
   [Улика про сад: смекалка/медицина ИЛИ Дед Фрол] — не точка невозврата,
   оба пути ведут к одному знанию
   [Продолжить травлю колодцев с Сестрой Любой? да/нет]
   ⇒ ТОЧКА НЕВОЗВРАТА 2 (мягкая): согласие останавливает
      возможность примирения Прогресс-2 и Чистых в Акте 3
        │
        ▼
  Q4 «Шесть пальцев» (НИИ) — ПОВОРОТ
   [Второй шаг правды: remont / arhiv / oba] → flag.vtoraya_pravda
   [Судьба Веденеева в сцене: напасть / уйти] → flag.vedeneev_sudba
   flag.shtamm0_pravda = true (устанавливается всегда по итогу квеста)
   ⇒ ТОЧКА НЕВОЗВРАТА 3: открывается Акт 3, дороги назад
      в «незнание про купель» нет
        │
        ▼
АКТ 3
  Q5 «Кому качать» (город)
   [Присяга: progress2 / energosbyt / chistye / neytralitet] → flag.storona
   ⇒ ТОЧКА НЕВОЗВРАТА 4: финальные линии двух непринятых
      фракций закрываются; если storona = energosbyt —
      дополнительно фиксируется предварительный flag.energosbyt_final
        │
        ▼
  Q6 «Труба» (финал)
   [Финальное действие] → flag.truba_deystviye
   ⇒ ТОЧКА НЕВОЗВРАТА 5 (последняя): конец игры, слайды эпилода
      по шести локациям (Гаражи, Плотина, Панели/Оголённая линия,
      Санаторий, НИИ + судьба Веденеева) на основании итоговых
      флагов и репутаций
```

## 5. Пять концовок — проверяемые условия

Условие каждой концовки — конъюнкция (все пункты одновременно). Если ни одна конъюнкция не выполнена целиком (нештатное состояние флагов), приоритет отдаётся скрытой концовке при её условии, иначе — «Чугунный век» как концовка по умолчанию (наименее требовательна к флагам, кроме `flag.storona`).

> **Пересчёт порогов `rep.chistye`/`rep.energosbyt` (2026-09-04, game-designer, по находке `docs/planerka/03-vs/duxa-review-vs-7.md` P0 №2).** Прежний порог `≥ 60` для обеих шкал был физически недостижим: исчерпывающий `grep` по всем узлам `public/data/dialogs/*.json`, дающим `incrementFlag rep.chistye`/`rep.energosbyt` (перепроверено вручную построчно, без доверия к предыдущим подсчётам), даёт честный максимум одного прохождения:
> - `rep.chistye`, максимум **40** = «Для колодца» (`act1-dlya-kolodtsa.json`, +15) + «Слушаю»→«Да, помогу» у Сестры Любы (`act2-sanatoriy-lyuba.json`, +10, доступно только если предыдущий узел выбран `privel`) + «Помочь лечебнице» у доктора Соломина (`act2-sanatoriy-solomin.json`, +15). Другие узлы на `rep.chistye` в диалогах игры отсутствуют.
> - `rep.energosbyt`, максимум **25** = «Отключить самому» на Рубильнике (`act1-rubilnik.json`, +15) + ветка «pro_rodiona_spas» у Зои (`act1-klyuch-zoi.json`, узел `rodion_zhiv`, +10, доступна только при `flag.prolog_vybor ∈ {spas, oba}`). После починки перехода `truba.exit_to_river → map.garazhi` эта ветка Зои реально проходима в одном честном прохождении без противоречий с Рубильником — проверено переходами `exits[]` в `public/data/maps/*.json`. Другие узлы на `rep.energosbyt` в диалогах игры отсутствуют.
>
> Три слагаемых из прежнего расчёта `docs/narrative/quests/act2-act3.md` §5 («максимум 65») в игре не применяются: `onEnter`-эффекты стадий `quest.shest_paltsev` никогда не срабатывают (квест-раннер, вызывающий `setQuestStage`, не реализован — задокументированное ограничение, не в этой волне), а диалог Клавдии Бусыгиной не существует ни одним файлом. По правилу «скоуп только сужается» (`CLAUDE.md`) решение — не дописывать раннер и диалог, а привести пороги концовок в соответствие с тем, что реально даёт существующий контент.
>
> Новые пороги ниже — примерно 75–80 % от честного максимума каждой шкалы, округлено до круглого числа: достаточно высоко, чтобы требовать целенаправленной, почти безошибочной игры за фракцию (не «`rep ≥ 0`» — это обнулило бы саму идею «выбор определяет исход»), но ниже жёсткого потолка, чтобы не требовать вычерпывания 100 % контента и не спотыкаться об одну неверную реплику. Пороги презяги (`≥ 40`, §2, Q5) и общая шкала статусов (§0.1) этим пересчётом не затронуты — они относятся к отдельному, отдельно известному ограничению (§3.3 `docs/narrative/quests/act2-act3.md`: диалог присяги сейчас не гейтится по репутации технически) и остаются задачей следующей волны.

### 5.1 «Второй сброс»

Пластик возвращается ценой леса и реки; Плотина становится империей, замыкающей на себе новый чёрный рынок пластика.

**Условие:**
```
flag.storona == "energosbyt"
AND flag.energosbyt_final == "polny_sbros"
AND flag.truba_deystviye == "vtoroy_sbros"
AND rep.energosbyt >= 20   // честный максимум прохождения — 25 (Рубильник +15 + Зоя «pro_rodiona_spas» +10); порог — 80%
AND flag.vedeneev_sudba != "mertv"   // нужен живой Веденеев, чтобы произвести штамм-0 в объёме
```

### 5.2 «Чугунный век»

Честная ржавчина: штамм-0 уничтожен вместе с лабораторией, ни одна фракция не получает решающего перевеса, трамвай №7 продолжает ходить.

**Условие:**
```
flag.storona IN ("progress2", "neytralitet")
AND flag.truba_deystviye == "chugunny_vek"
AND rep.progress2 >= 20   // не обязательно "свои", но и не враги
```

### 5.3 «Пусть течёт»

Плотина взорвана усилиями Чистых, город рассыпается на речные деревни вдоль Ольхи.

**Условие:**
```
flag.storona == "chistye"
AND flag.truba_deystviye == "vzryv_plotiny"
AND rep.chistye >= 30   // честный максимум прохождения — 40 («Для колодца» +15 + Люба +10 + Соломин +15); порог — 75%
```

### 5.4 «По счётчику»

Штамм-0 остаётся у Энергосбыта под дозированным контролем; восстановление идёт по тарифу, герой лично становится начальником Трубы.

**Условие:**
```
flag.storona == "energosbyt"
AND flag.energosbyt_final == "dozirovka"
AND flag.truba_deystviye == "po_schetchiku"
AND rep.energosbyt >= 20   // тот же честный максимум и порог, что и в 5.1 — обе энергосбытовские концовки делят одну шкалу
```

### 5.5 «Очень чистый» (скрытая)

Игрок с низким интеллектом сам выпивает штамм-0 в финальной сцене — реплика доступна независимо от того, какой стороне присягнул герой, единственное условие — характеристика.

**Условие:**
```
Смекалка <= 3   // порог низкого интеллекта, единый с диалоговыми ветками низкого интеллекта в других квестах
AND flag.truba_deystviye == "ochen_chisty"
// flag.storona может быть любым — этот исход перекрывает финальный выбор в момент диалога в Q6
```

**Примечание.** Диалоговая опция, ведущая к `flag.truba_deystviye = "ochen_chisty"`, физически показывается в UI сцены Q6 только при `Смекалка ≤ 3` — так скрытая концовка остаётся «скрытой» без отдельного секретного триггера вне характеристик персонажа.
