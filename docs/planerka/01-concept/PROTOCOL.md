# Протокол планёрки №1 — концепт игры «Outfall»

Дата: 2026-09-03. Ведущий: системный архитектор. Участники: game-designer, narrative-writer, engine-architect, art-director, audience-analyst. Второй раунд: duxa-simulator, audience-analyst (оценка по рубрике), producer (бэклог).

## Вопрос
Какую игру под названием «Outfall» мы делаем, чтобы Андрей (DЮХA) захотел снять на неё ролик формата «Про …»?

## Варианты, которые рассматривались
| Область | Варианты | Решение | Обоснование |
|---|---|---|---|
| Мир и сюжет | A «Водосброс» (бактерия съела пластик, город на плотине) / B «Выпавшие» (уральский провал, соляная пустошь) / C «Прогон» (город внутри советской ЭВМ) | **A** | Название объясняется буквально, пересказывается по формуле канала, постсоветский колорит — правило мира. Из B берём самоназвание «Выпавшие» для беженцев, из C — одну мета-шутку |
| Ядро геймплея | A «Свинец и Шаг» (твин-стик, позиция/патроны/рывок, КОСТЯК) / B «Кураж под огнём» (push-forward) / C «По частям» (зоны тела, травмы) | **A** | Прямо совпадает с миссией; каждая механика — формула на 1–2 дня; Кураж и травмы добавляемы позже |
| Подзаголовок | «Пустошь по ГОСТу» и 4 других | **«Пустошь по ГОСТу»**, лор-строка «Куда всё стекает» | Снимает риск «клон Fallout», совпадает с формулой заголовка «Русский Fallout от …» (52 тыс.) |
| Рендер | Canvas 2D / PixiJS 8 / Phaser 3 | **PixiJS 8** за `IRenderer` | 60 FPS на 200+ спрайтах, тестируемость через `NullRenderer`, малый бандл |
| Тик симуляции | 30 Гц / 60 Гц | **60 Гц** | Динамика — ключевое обещание; откат к 30 только по профилю |
| UI | DOM / Pixi | **DOM для экранов, Pixi для HUD** | Русский текст, доступность, скорость разработки |
| Стиль | «грязный пиксель 90-х» / «чистый пиксель, грязный мир» | **«чистый пиксель, грязный мир»** | Читаемость боя при узнаваемой серо-бурой гамме |
| Генератор персонажа | перед стартом / по кнопке | **по кнопке, пресет по умолчанию** | Первый бой и выбор — до 60-й секунды |
| Носимый «компьютер» | браслет / нет | **нет: «Щиток» + наряд-книжка** | Прямой запрет из профиля ЦА |
