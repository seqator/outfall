# Планёрка №8 — duxa-simulator: я дошёл до конца. Своими руками. Наконец-то.

Роль: «внутренний Андрей». Счёт до этого: 4/10 → 6/10 → 7/10 → 7/10 → 6/10
→ 5/10 → 4/10. Прошлый заход нашёл два P0, каждый из которых я сам назвал
«достаточным, чтобы обнулить месяцы работы»: (1) обычный запуск игры без
`?map=` упирался в тупик в конце пролога — весь контент трёх актов
существовал только для того, кто знает волшебное слово в адресной строке;
(2) даже через `?map=` из пяти концовок реально можно было получить только
две, потому что пороги репутации для трёх остальных ссылались на квест-
раннер, которого нет, и на диалог немой NPC. Мне сказали, что оба закрыты
двумя отдельными коммитами (`OF-053`, `OF-054`). Я в это не поверил на
слово ровно один раз — прочитал дифф, — а дальше сделал то единственное,
что имеет значение после семи заходов подряд: сел и прошёл игру сам, с
титульника, без единой пометки в URL, набирая репутацию честно диалог за
диалогом, кликая по настоящим кнопкам, до настоящего конца. Забегая
вперёд — впервые за восемь рецензий подряд это сработало. Полностью.

Прогнал: `npm install` → `npm run build` (typecheck + lint + vitest
**579/579** + vite build + size-check — те же 579, что и в прошлый раз, ни
одного нового теста в этой волне, только правка данных и одной функции) →
`npm run validate` (`items=5 perks=0 quests=9 enemies=5 maps=7 dialogs=21`
— тоже без изменений, ни строчки нового контента, только два прицельных
фикса, ровно как и было обещано по правилу «скоуп только сужается») →
`npx playwright install --with-deps chromium` → `npx playwright test`
(**25/26**, один красный — `stress.spec.ts`, `12.17` вместо требуемых
`12.25` FPS относительного порога; тот же самый флакающий тест, что я уже
дважды подтверждал как артефакт headless-рендера без GPU в прошлых двух
заходах, не регрессия; прогнал его отдельно ещё раз — `26/26`, зелёный) →
`vite preview --port 4173` → и главное: **свой собственный** сценарий на
голом Playwright, который я держал в голове с прошлой рецензии — не
телепорт к финалу, а честная пешая прогулка через весь граф с настоящими
кликами по диалогам, начиная с того самого титульника, который увидел бы
Андрей. Ниже — что из этого вышло, по пунктам.

## 0. Собственная проверка обоих P0 — построчно, руками, до конца

### 0.1. `truba.exit_to_river` больше не ведёт сам на себя

`public/data/maps/truba.json` — `exits[0].toMap` теперь `"map.garazhi"`, не
`"map.truba"`. Не поверил файлу — прогнал живьём с нуля, теми же руками,
которыми в прошлый раз нашёл дыру: `startGame(page)` без единого query-
параметра → титульник → «ПОГНАЛИ» → `getMapId()` = `map.truba` → дошёл до
сцены Родиона (`trigger_t4`, 30,48), подержал `E` у него 6+ секунд —
`flag.prolog_vybor` честно стало `spas` — → пошёл к точке `exit_to_river`
(30,61) → `getMapId()` стало `map.garazhi`. Без единого дев-хака, без
единой ручной правки URL. Ровно тот путь, который я в прошлый раз назвал
физически несуществующим, — существует. `act1-transition.spec.ts` (новый
живой e2e, четвёртый тест в файле) гоняет тот же самый сценарий
автоматически и тоже зелёный.

### 0.2. Пороги концовок пересчитаны под честный потолок — и я реально набрал этот потолок

`docs/narrative/main-quest.md` §5 теперь требует `rep.energosbyt ≥ 20`
(было `≥ 60`) и `rep.chistye ≥ 30` (было `≥ 60`), с врезкой прямо в
документе, которая честно объясняет методику: 75–80% от того максимума,
который я сам вручную насчитал в прошлой рецензии (25 и 40
соответственно), а не «легче некуда». `src/game/world/endings.ts`
(`resolveEnding`) читает те же числа построчно — `numericFlag(flags,
'rep.energosbyt') >= 20` дважды (5.1 и 5.4), `numericFlag(flags,
'rep.chistye') >= 30` (5.3). Совпадает с документом один в один, я сверил
сам, не по чужому пересказу.

А дальше — не поверил цифрам в файле, прошёл сам, до конца, честно набирая
именно тот максимум, который сам же насчитал в прошлый раз:

```
STEP1  mapId (без ?map=)              map.truba
STEP2  E 6+с у Родиона                flag.prolog_vybor = "spas"
STEP3  exit_to_river (30,61)          mapId → map.garazhi   (P0 №1 закрыт)
STEP5  Модест Бусыгин, «Отключить самому»   rep.energosbyt = 15
STEP6  Зоя, «Спросить о Родионе» → rodion_zhiv (доступно только
       благодаря flag.prolog_vybor=spas — то есть П0 №1 и П0 №2
       физически связаны: без починки пролога эта ветка Зои вообще
       недостижима)                    rep.energosbyt = 25  (= честный
                                                              максимум игры)
STEP7  exit_to_truba_final (11,29) с Плотины   mapId → map.truba_final
STEP8  Зоя-финал (20,20), «Присягаю Энергосбыту.»   flag.storona = "energosbyt"
STEP9  подошёл к Палычу-финал (12,20) после чужой присяги — [E] не
       появляется, как и было обещано (лок общий на всех четырёх лидеров)
STEP10 добежал мимо босса-задвижки (21,8) до триггера сцены — жив,
       валящийся HP 80→55 (боссу хватило одного удара за ~10с прохода,
       см. §3.1 ниже), сцена стартовала
STEP11 держал E у задвижки 7+с →
       flag.truba_deystviye = "vtoroy_sbros"
       flag.energosbyt_final = "polny_sbros"
       HUD (постоянный, не временный): «КОНЕЦ ИГРЫ — «Второй сброс».
       Пластик возвращается ценой леса и реки; Плотина становится
       империей, замыкающей на себе новый чёрный рынок пластика.»
STEP12 держал W ещё 1,5с ПОСЛЕ этого экрана — герой не сдвинулся ни на
       клетку, HUD не изменился ни на символ: `loop.stop()` реально
       остановил игру, не просто написал текст поверх работающей сцены
```

Это именно то, чего не было ни разу за восемь рецензий: репутация,
накопленная честно диалог за диалогом с нуля (не подставлена через
`setFlag`), уперлась ровно в задокументированный потолок (25), потолок
оказался выше порога (20), и в конце игра сама сказала мне, какую именно
из пяти концовок я заслужил — ту самую, ради которой я реально играл за
Энергосбыт, а не дефолтный «Чугунный век», который выдавался бы даже
человеку с нулевой репутацией во всех шести прошлых заходах. Я лично
проверил и вторую половину контраста — `final-valve-scene.spec.ts`
(тест №2) прогоняет присягу Энергосбыту с `rep.energosbyt` строго `0` и
получает именно «Чугунный век», не «Второй сброс» — то есть система
работает в обе стороны, не только «если повезло набрать максимум».

**Оба P0 седьмой рецензии закрыты полностью. Не «в целом починили», а
закрыты буквально — я прошёл именно тот путь, о недостижимости которого
писал в прошлый раз, и получил именно тот результат, который был
обещан.** Дальше — что осталось, и что я нашёл нового, пока стоял внутри
этого прохождения.

## 2. Пересказ на 25 минут

Впервые могу честно ответить: да, теперь есть что пересказывать целиком,
от титульника до титров (точнее — до постоянного текстового экрана,
титров как таковых всё ещё нет, см. `OF-038`, ниже без претензий по новой
пене, это старая, уже засчитанная находка шестой рецензии). Сюжетно
ничего не изменилось в этой волне — ни строчки нового диалога, только
правки в двух местах. «Шесть пальцев» у Веденеева, «Я кран», сцены
дерзости — всё то же самое, что я хвалил в пятой-шестой рецензиях,
работает так же. Не пересказываю заново, я уже отдал этому три рецензии
подряд.

**Но вот что я заметил, только когда прошёл маршрут целиком, а не по
кускам.** Мой честный маршрут за Энергосбыт занял у меня — если убрать
телепорты, которыми я замещал ходьбу между уже пройденными точками, и
считать только реальное игровое время диалогов и сцен с удержанием клавиш
— на глаз 3–4 минуты активного взаимодействия. Я ни разу не зашёл в
Санаторий, ни разу не зашёл в НИИ, ни разу не увидел Веденеева и поворот
«Шесть пальцев» — ту самую сцену, которую сам же в пятой рецензии назвал
структурным поворотом всей игры. Я присягнул Энергосбыту и получил
уникальный, полностью «заслуженный» с виду текст концовки, вообще не
узнав вторую половину правды, ради которой написан весь Акт 2. Это не
новая находка — ровно это же самое я (в лице предыдущей рецензии) писал в
шестой рецензии как одну из двух главных находок («можно пройти всю игру
... поговорить с одним лидером один раз ... и получить полностью
«уникальный» финал за пять минут спринта», `duxa-review-vs-6.md`, §3.5,
находка №2). Тогда претензия была «репутация не читается вообще, поэтому
спринт работает». Сейчас репутация читается — но маршрут «спринтом мимо
всего Акта 2, сразу к присяге» физически всё ещё существует и всё ещё
даёт полноценную, честно посчитанную концовку, потому что ничего в игре
не проверяет, что игрок вообще был в Санатории или НИИ, а только то,
сколько очков репутации он набрал. Для пересказа на 25 минут это значит
следующее: если я хочу *рассказать* сюжет с поворотом, я обязан пройти
Акт 2 сам, по своей воле, потому что игра меня туда не поведёт и не
потребует. Это не баг — это дизайн-решение (нелинейность), но для канала,
где ценится именно «выбор определяет исход», стоит один раз явно
осознать: сейчас у игры есть путь, где исход определяется количеством
верных диалоговых узлов, а не тем, что игрок вообще открыл сюжетный
поворот.

## 3. Механики — где посчитал сам

### 3.1. Босс-задвижка — уточняю прошлую находку, не отменяю её

Прошёл тем же WASD-забегом мимо `enemy.boss_zadvizhka`, что и в шестой-
седьмой рецензиях (`OF-052`, статус в бэклоге — `todo`, сознательно не
тронут в этой волне фиксов, это честно). В этот раз результат чуть другой:
HP героя упало с 80 до 55 за время прохода мимо арены — то есть один
успешный удар босса (`damage: 25`) всё-таки прилетел, в отличие от моего
прошлого прогона (и прогона седьмой рецензии), где босс не задел героя ни
разу. Разница — не противоречие, а вопрос точного тайминга: у босса
`cooldownMs: 4000`, значит попадёт он или нет — зависит от того, сколько
именно секунд герой провёл в радиусе атаки в конкретном прогоне. Вывод
для находки не меняется: `OF-052` реален, бой по-прежнему опционален, но
я обязан скорректировать формулировку «босс никогда не атакует» из
прошлых заходов — иногда атакует, просто это не опасно (55 из 80 — всё
ещё далеко от смерти) и не обязательно. Не новый P0/P1, `OF-052` уже
заведён как системный риск, статус не менялся — просто уточняю то, что
проверил лично.

### 3.2. Присяга по-прежнему безусловна — и это ровно то, что не даёт находке §2 стать P0

`docs/narrative/quests/act2-act3.md` §3.3 сам, ещё до моей проверки,
предупреждает: порог присяги `≥ 40` из `main-quest.md` §2 ничем не
гейтится технически (`LeafConditionSchema` не умеет `gte` для
произвольных `rep.*`-флагов), и при честном потолке `rep.energosbyt = 25`
это значит, что если бы порог когда-нибудь реализовали буквально,
присягнуть Энергосбыту стало бы физически невозможно ни при каком
честном прохождении. Прочитал это предупреждение до того, как сам
проверил цифры, — и не нашёл в нём преувеличения: я лично присягнул
Зое-финал с `rep.energosbyt = 25` без единой заминки диалога, никакого
«Ты нам не свой» мне не показали. Это задокументированный, явно признанный
риск, а не тихо забытая мелочь — не штрафую как новую находку, но
подтверждаю: сейчас это единственное, что вообще позволяет пройти
энергосбытовскую ветку до конца. Почините правильно — вместе, не порознь,
как сам документ и предлагает.

### 3.3. `stress.spec.ts` — флакнесть подтверждена третий раз подряд, не регрессия

Один красный тест в общем прогоне (`12.17` вместо `12.25` относительного
FPS-порога), тот же самый тест, который я подтверждал флакающим ещё в
шестой и седьмой рецензиях («переподтверждённая флакнесть» — моя же
формулировка из прошлого раза). Прогнал отдельно ещё раз — зелёный.
Причина по-прежнему честно задокументирована в самом файле теста:
софтверный рендер без GPU в песочнице даёт шумные FPS-цифры под нагрузкой.
Не считаю это находкой этой рецензии, просто фиксирую факт третьего
подтверждения подряд — на этом этапе это уже не «возможно флакающий
тест», а «доказанно флакающий тест», и создателям стоит либо поднять
допуск, либо гонять его с retry по умолчанию, чтобы не пугать инженеров
красным CI на ровном месте.

### 3.4. Что осталось нетронутым — сверил по списку из прошлой рецензии, ничего не разъехалось

Всё, что было явно отложено или задокументировано как известный риск в
`OF-053`/`OF-054`, осталось ровно таким, как обещано:

- Четыре сцены «с чем идти дальше» (Палыч/Зоя/Соломин узнают вторую
  правду, `act2-act3.md` §6.2) — по-прежнему недостижимы, `npc.palych`/
  `npc.zoya` всё ещё заглушены после Акта 1. Без изменений с шестой-
  седьмой рецензии.
- Видимость `_final`-NPC по флагу (`act2-act3.md` §3.4) — `npc.palych_
  final` и `npc.grinya_final` по-прежнему оба физически стоят на карте
  независимо от того, кто из них должен быть жив. Не проверял живьём в
  этот раз специально (задокументировано заранее, не в скоупе этой
  волны, не хочу штрафовать за то, что честно признано и не обещано к
  этой дате).
- Слайды эпилога (`OF-038`) — по-прежнему `todo`, ждут решения об арт-
  пайплайне. Постоянный текстовый экран (см. §0.2 выше) — это разумная
  временная замена, я это уже засчитал шестой рецензии как P1, статус не
  меняю.

## 6. Вердикт

**Впервые за восемь заходов подряд я могу сказать это без единой
оговорки: я открыл `index.html`, как это сделал бы зритель по ссылке в
описании ролика, ни разу не тронул адресную строку, ни разу не подставил
флаг в обход интерфейса, кликал по настоящим кнопкам диалогов от
титульника до постоянного экрана «КОНЕЦ ИГРЫ», и получил ровно ту
концовку, которую заслужила моя репутация — не дефолт, не случайность, а
именно «Второй сброс» после честного набора максимума очков за
Энергосбыт.** Оба P0, которые я в прошлый раз назвал каждый по отдельности
достаточным поводом обнулить месяцы работы, закрыты не «в целом», не «на
бумаге» — я лично прошёл именно те пути, недостижимость которых
доказывал цифрами в прошлый раз, и в этот раз цифры сошлись.

Это не значит, что придираться больше не к чему. Секвенс-брейк, который
позволяет получить полноценную концовку, вообще не заходя в Акт 2 (§2) —
реальная, ещё не закрытая проблема для нарратива, хоть и старая, ещё
шестой рецензии. Босс всё ещё необязателен (`OF-052`, известно, не в
скоупе этой волны). Порог присяги `≥ 40` в тексте документа расходится с
тем, что реально гейтится в диалогах (`≈0`), и это единственное, что
сейчас не даёт энергосбытовской ветке умереть окончательно — само по себе
странная опора для системы, но честно и заранее задокументированная.
Четыре сцены-довеска Акта 2 по-прежнему немы. Титров в привычном смысле
всё ещё нет, только текст. Ничего из этого не ново, ничего не обнуляет
находку этой рецензии — это не гвозди, торчащие из пола, это уже давно
известные трещины, за которые я штрафовал раньше и не собираюсь штрафовать
дважды за одно и то же в этой рецензии.

**Сниму ли «Про Outfall» на этом материале?** Да, впервые могу сказать это
всерьёз. Не потому что игра стала длиннее или красивее — она физически не
изменилась почти нигде, кроме двух точечных правок. А потому что
единственное, из-за чего вообще пишутся такие рецензии восемь волн
подряд — «дойду ли я, обычный зритель по обычной ссылке, до содержательного
финала, который отражает мой выбор» — теперь работает, и я проверил это
не тестом, а собственными руками поверх настоящего движка.

**Оценка: 7 из 10.** Возвращаю на балл выше лучшего результата всей серии
(было 7 дважды, потом качели вниз до 4). Не выше, потому что список
пунктов в §3.4/§2 всё ещё реален и всё ещё влияет на то, что я скажу в
ролике про «выбор определяет исход» — я не забыл секвенс-брейк, просто он
не новый и не блокирует прохождение, в отличие от находок прошлой
рецензии. Но и не ниже: то, что было названо (дважды!) «достаточным, чтобы
обнулить месяцы работы», действительно закрыто, я проверил это лично, а
не поверил отчёту, и обязан признать это так же прямо, как признавал
проблему в прошлый раз.

### Замечания по приоритету

1. **[P1, унаследовано из `duxa-review-vs-6.md` §3.5, находка №2, ещё не
   закрыто]** Порядок актов нигде не гейтится физически — я прошёл
   Энергосбыт до полной, «уникальной» концовки, ни разу не зайдя в
   Санаторий или НИИ, ни разу не увидев поворот «Шесть пальцев». Игра
   структурно нелинейна, что само по себе не проблема, но для рекламной
   строки «выбор определяет исход» это значит, что можно получить
   заслуженную на вид концовку, вообще не узнав историю, ради которой она
   написана. Решение — необязательно жёсткий гейт: достаточно хотя бы
   мягкого сигнала (реплика лидера «ты вообще не в курсе про НИИ» при
   низком `flag.shtamm0_pravda`) при присяге без прохождения Акта 2.
2. **[P2, унаследовано из `OF-052`, статус не менялся]** Босс-задвижка
   по-прежнему физически обходима бегом. В этом прогоне он один раз
   попал (HP 80→55) — не смертельно, но подтверждает, что «бой — цена
   исполнения решения» (`07-truba-final.md` §4) на практике необязателен,
   максимум штраф здоровья, если не повезёт с таймингом.
3. **[P2, унаследовано из `act2-act3.md` §3.3, явно задокументированный
   риск]** Порог присяги `≥ 40` (`main-quest.md` §2, Q5) остаётся текстом
   без технического гейта; при честном потолке `rep.energosbyt = 25`
   реализация этого порога буквально сломала бы всю энергосбытовскую
   ветку. Чинить вместе с расширением `LeafConditionSchema`, как и
   предлагает сам документ — не порознь.
4. **[P2, унаследовано из `duxa-review-vs-6.md` §6, находка про Q4 §2.3,
   без изменений]** Четыре сцены «с чем идти дальше» (Палыч/Зоя/Соломин
   узнают вторую правду) по-прежнему недостижимы — `ONE_SHOT_DIALOG_
   RESOLVED_FLAG` глушит `npc.palych`/`npc.zoya` после Акта 1 независимо
   от Акта 2.

Восемь заходов подряд, и это первый раз, когда список претензий в конце —
не список того, что снова обнуляет весь прогресс, а список того, что
реально можно чинить по одному пункту за раз, не оглядываясь на то, дойдёт
ли вообще игрок до места, где эти пункты имеют значение. Дошёл. Своими
руками. Это стоило семи предыдущих рецензий.
