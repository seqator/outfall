# Outfall — правила репозитория для агентов

Прочитай `docs/00-MASTER-PROMPT.md` перед началом любой работы. Там: роль, миссия, ЦА, границы продукта, процесс.

## Быстрые факты
- Игра «Outfall»: изометрический реалтайм экшен-RPG в пост-апокалипсисе, браузер, TypeScript + Vite, русский язык.
- Целевая аудитория: зрители канала DЮХA (`docs/research/andrey-channel-profile.md`).
- Концепт и решения: `docs/OUTFALL-CONCEPT.md`, протоколы планёрок в `docs/planerka/`.
- Агенты команды: `.claude/agents/`. Один агент — одна зона ответственности.

## Правила
- Решения фиксируются в `docs/`, не в чате.
- Скоуп только сужается. Каждая итерация заканчивается рабочей сборкой.
- Никаких чужих копирайтных ассетов и имён из Fallout. Оммаж, не клон.
- Без внешних запросов в рантайме, без секретов в репозитории.
- TypeScript strict, тесты на игровую логику, 60 FPS.
- Коммиты маленькие, ветка `claude/outfall-game-concept-73eqjh`.
